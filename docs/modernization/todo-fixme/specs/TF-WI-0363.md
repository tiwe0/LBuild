# TF-WI-0363: ARM64 ldnp pair opcode contract

- **基线标记：** `Lambda64/system/disassemble-arm64.lisp` load/store pair decoder
- **代码事实源：** `Lambda64/system/disassemble-arm64.lisp:108-149`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

保持 ARM64 pair 指令的架构分类：non-temporal load 使用独立 `ldnp` 操作码，不能退化为普通
`LDP`/`STP`。解码器同时保留 SIMD/FP 宽度、寻址模式与寄存器对的既有逻辑。

## 当前边界

生产解码器已根据 non-temporal 位与 load/store 位选择 `ldnp`，并在整数 32/64 位
组合中将 LDPWS 单独分类。该工作项只移除已实现分支上的历史 `lap todo` 注释；不改变
编码或扩大对保留编码的接受范围。

## 验收证据

`Lambda64/tests/host/test-system-disassemble-arm64-pair.sh` 提取生产解码器，检查上述
操作码分支、拒绝历史 marker，并通过变异 non-temporal load 分支确保分类不会被误删。
该测试是 host fixture；cold-image/integration 证据仍待后续硬件/镜像批次补齐，故状态
保持 `active`。
