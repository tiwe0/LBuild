# TF-WI-0406 — Reader 浮点格式与精度

- **基线标记：** `TF-occ-9dd78389512cbeba50ea9079`
- **代码事实源：** `Lambda64/system/reader.lisp:358-454`
- **风险：** high
- **要求测试层：** host、codegen、cold-image

## 目标

`read-float` 在最终 `COERCE` 前使用整数/有理数计算尾数和指数，避免中间
双精度舍入；随后按 `S/F/D/L` 标记或 `*read-default-float-format*` 选择目标格式。

## 先测试证据

新增 `Lambda64/tests/host/test-system-reader-float-selection.sh`，检查精确整数尾数、
整数指数幂和显式格式映射；变异负例恢复双精度累加，必须被测试拒绝。实现前测试因
旧 TODO 和 `10.0d0` 中间转换而失败。

## 验收标准

1. 大整数和小数尾数在转换前不经过固定双精度中间值。
2. `S/F/D/L/E` 标记继续映射到正确的目标类型。
3. 指数正负号保持原有语义，非法 token 仍返回失败。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
