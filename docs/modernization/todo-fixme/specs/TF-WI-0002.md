# TF-WI-0002: Telnet UTF-8 output encoding contract

## Scope

This specification defines the byte encoding applied to characters produced by
`mezzano.gui.xterm:input-translate` before they are written to the Telnet
connection in `Lambda64/applications/telnet.lisp`. It resolves the baseline
directive at the former line 205. The receive path, Telnet command parser, and
negotiation state are outside this work item.

## Required behavior

- Every translated character is encoded as canonical UTF-8 before it is sent.
  Two-, three-, and four-byte Unicode scalar values are supported.
- Encoding reuses `mezzano.internals::encode-utf-8-string` with LF end-of-line
  behavior. Invalid scalar values, including UTF-16 surrogates, retain that
  encoder's U+FFFD replacement semantics.
- ASCII bytes, including NUL, escape-sequence bytes, CR, and LF, retain their
  original byte values. Encoding does not apply newline or terminal semantics.
- UTF-8 bytes are treated as Telnet data. Every byte equal to IAC (`255`) is
  doubled before transmission so it cannot be interpreted as a command marker.
- U+00FF is encoded as UTF-8 bytes `C3 BF`; it is not treated as a raw IAC byte.
- The Telnet-specific helpers introduce no new dependency.

## Acceptance evidence

`Lambda64/tests/host/test-telnet-utf8-send.sh` extracts and executes the pure
output helpers. It covers empty input, ASCII control and escape-sequence bytes,
representative two-, three-, and four-byte UTF-8 characters, U+00FF, and single
and adjacent IAC bytes in a data payload. The host encoder stub also requires a
single-character string and `:eol-style :lf`, and mirrors invalid-scalar
replacement with U+FFFD when the host Common Lisp exposes surrogate characters.

Before implementation, the focused test failed with
`Missing Telnet output helper "%telnet-iac-escape-octets"`. The focused host
test, documentation checks, and `git diff --check` are required local evidence.
The work item must not be recorded as verified until the governance ledger is
frozen and its separately required guest evidence exists.
