# TF-WI-0316 — `adjust-array` 的 unusual array 支持

- **基线标记：** `TF-occ-21abbedb4e1715119268c74e`
- **代码事实源：** `Lambda64/system/array.lisp:486-606`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

调整 displaced 或 memory-backed array 时不再无条件报错。由于两类 array 的 backing
storage 均不可安全地原地扩容，结果使用新的普通、可调整 storage；在没有
`:initial-contents` 时保留原 array 可见的 row-major 重叠前缀，新扩展部分遵循
`:initial-element` 的既有规则。已有的 vector fill-pointer 会被带到返回结果，原
displacement/memory storage 不被写入或重分配。

这与 `adjust-array` 在未重新声明 displacement 时返回独立 data region 的 Common
Lisp 语义一致；本工作项不增加新的 `:displaced-to` API 参数。

## 先测试证据

`Lambda64/tests/host/test-system-array-unusual-adjust.sh` 在旧实现上运行失败，错误为：

```text
TODO: Adjusting unusual array ...
```

该回归以一个表示层 fixture 覆盖 displaced 和 memory-backed array 的 row-major
前缀拷贝、旧 storage 不变、`initial-element`、`initial-contents` 和 fill-pointer
保留；并通过 prefix-copy mutation 负例确保拷贝路径不可被删除。
