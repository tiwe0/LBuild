# TF-WI-0087: Define Intel HDA output routing boundary

## Scope

Close the output-routing TODO in `Lambda64/drivers/intel-hda.lisp` without
changing the current playback behavior.

## Contract

`mezzano.driver.sound:sound-card-run` selects one playback path through
`default-output-pin`. Supporting every output-like pin requires an explicit
fan-out policy covering converter format negotiation, DMA-buffer ownership,
independent stream teardown, and hardware synchronization. Until that policy
and hardware-level coverage exist, the driver intentionally keeps the
single-pin contract.

## Verification

`Lambda64/tests/host/test-intel-hda-output-routing-boundary.sh` checks that the
stale TODO is closed and that the single-pin selection contract remains
explicit in the implementation.
