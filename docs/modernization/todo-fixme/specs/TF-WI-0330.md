# TF-WI-0330: Ordered around-method next-methods

## Scope

This work item closes the corresponding CLOS runtime marker in
`Lambda64/system/clos/closette.lisp`.

## Required behavior

- Removing the current around method retains the complete ordered applicable
  method list, including a more-specific primary that sorts before that around
  method. The next-method list then contains only remaining around and primary
  methods; before/after methods are excluded.
- Existing bootstrap-safe paths and standard generic-function fast paths remain available.

## Test-before evidence

The old next-method list included all qualifiers. The focused source-contract test failed against that implementation.

## Acceptance evidence

`Lambda64/tests/host/test-system-closette-modernization.sh` rejects the former
`cdr/member` truncation and requires a single-method removal. The production
function is extracted by `test-system-closette-behavior.sh`; an integer primary
ordered before a number around and number primary returns `(:AROUND :INTEGER)`.
The focused tests and Lisp style checks pass. A cold-image build and guest
CLOS redefinition/dispatch exercise remain outstanding, so this item stays active.
