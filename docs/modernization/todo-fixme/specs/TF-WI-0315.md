# TF-WI-0315 — `adjust-array` 的非 vector 支持

- **基线标记：** `TF-occ-87c7215e7f6ed5e831f040ec`
- **代码事实源：** `Lambda64/system/array.lisp:486`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

非 vector 的普通及 character-backed complex array 可按新维度调整：backing storage
按新 row-major 总容量调整，header 的每一维同步更新，已有元素按 row-major 前缀保留。
`:fill-pointer` 仍只允许 vector；displaced 等 unusual array 仍由独立工作项处理。

## 先测试证据

旧实现无条件发出 `TODO: adjust-array on non-vectors.`，因此二维数组无法进入已有
complex-array storage 调整路径。
