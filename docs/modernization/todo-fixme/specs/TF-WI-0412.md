# TF-WI-0412 — `(setf macro-function)` 的 environment 策略

- **基线标记：** `TF-occ-22f44912510f3730203f29d9`
- **代码事实源：** `Lambda64/system/runtime-support.lisp:191-224`
- **风险：** medium
- **要求测试层：** host、cold-image、integration

## 目标

`macro-function` 的环境参数仅用于查询 lexical macro definition。对非空 environment
执行 `(setf macro-function)` 在 Common Lisp 中没有定义的语义，因此 Lambda64 现在明确
拒绝该调用并发出 `simple-program-error`；全局 macro definition 的设置和清除保持原有
语义，且不会被失败的 lexical 请求修改。

## 先测试证据

`Lambda64/tests/host/test-system-runtime-support-macro-environment.sh` 在旧实现上失败：

```text
non-global macro definition did not signal PROGRAM-ERROR
```

该回归验证全局 macro definition 的设置和清除、非空 environment 的 `program-error`，以及
失败请求不改变已存在的全局 definition。mutation 负例将专用 condition 改回普通 error，
确保环境策略不会退化为未分类的 TODO 异常。
