# TF-WI-0125: File-cache stream sequence write contract

## Scope

This specification closes the sequence-write requirement at
`Lambda64/file/cache.lisp:90`. It preserves the existing byte-write behavior
while giving `file-cache-stream` a block-aware Gray stream sequence method.

## Required behavior

- The method honors the source `start`/`end` interval and returns the original
  sequence.
- It writes the exact selected elements at the current file position, spans
  cache blocks correctly, updates position and logical length, and marks every
  modified block dirty.
- Moving to a different cache block flushes a dirty current block before it is
  replaced. Writing beyond EOF allocates required blocks and zero-initializes
  unwritten bytes through the existing allocator.
- An empty selected interval performs no I/O and leaves stream state unchanged.
- An invalid `start`/`end` interval signals before it can flush, allocate, or
  modify a cache block.

## Acceptance evidence

`Lambda64/tests/host/test-file-cache-sequences.sh` must cover writes spanning
three blocks, nonzero source bounds, extension/allocation, flush behavior, and
an empty interval. The focused test and `make test-fast` are required before
this work item may be verified.
