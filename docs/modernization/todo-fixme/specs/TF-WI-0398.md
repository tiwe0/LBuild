# TF-WI-0398: Stack-allocated bignum canonicalization boundary

The x86 canonicalizer may return an existing heap bignum when its canonical
size is unchanged. Supporting stack-allocated bignums requires an allocation
and copy path that preserves GC liveness and canonical sign extension; defer
that change until cold-image and integration tests cover those lifetimes.
