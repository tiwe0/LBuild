# TF-WI-0481: Define x86 memref CAS codegen boundary

## Scope

Close the `(cas memref-t)` TODO in
`Lambda64/compiler/backend/x86-64/memory.lisp`.

## Contract

The x86 backend's `cmpxchg` IR instruction currently models object-relative
slots, whereas `memref-t` computes a raw effective address from base and index.
The operation remains unsupported rather than lowering through an unrelated
object slot. Implementing it requires a dedicated IR/codegen form that carries
arbitrary address operands and specifies the required memory ordering (and
`dcas` would require the corresponding 16-byte form).

## Verification

`Lambda64/tests/host/test-compiler-x86-memref-cas-boundary.sh` checks that the
TODO is closed and that the address/codegen and memory-order prerequisites are
documented.
