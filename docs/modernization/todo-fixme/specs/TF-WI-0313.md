# TF-WI-0313 — LOOP typed initializer 的 sized vector 支持

- **基线标记：** `TF-occ-56f15e4ed73d33658bfccd3e`
- **代码事实源：** `Lambda64/system/ansi-loop.lisp:1091-1118`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`loop-typed-init` 对 vector 类型不能只调用 `coerce nil`：该操作只能产生空向量，
无法满足 `(vector element-type size)` 的长度约束。类型展开后若得到单一整数维度，
应直接创建对应长度和元素类型的数组；无固定长度的 vector 类型继续沿用空向量回退。

## 先测试证据

新增 `Lambda64/tests/host/test-system-ansi-loop-typed-init-vectors.sh`，检查 sized-vector
分支解析元素类型与维度、调用 `make-array`，同时保留 `coerce` 回退；移除直接分配的
变异必须被拒绝。

## 验收标准

1. `(vector element-type size)` 与等价的 `simple-vector` 类型生成指定长度的向量。
2. 不定长或无法解析为单一维度的 vector 类型保持原有空向量初始化。
3. 现有 float、number 初始化分支保持不变。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
