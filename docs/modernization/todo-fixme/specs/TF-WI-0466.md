# TF-WI-0466: Isolate GC finalizer errors

## Scope

`run-finalizers` catches errors from each callback, reports them through the
supervisor console without allowing reporter failures to abort the queue, and
always clears the callback reference in `unwind-protect`.

## Verification

`Lambda64/tests/host/test-system-gc-finalizer-errors.sh` executes a minimal
queue fixture covering callback failures, reporter failures, continuation, and
weak-pointer cleanup; mutation negatives remove the protection paths. Full
GC-worker and cold-image validation remains required before completion.
