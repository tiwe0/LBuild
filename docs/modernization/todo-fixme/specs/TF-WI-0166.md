# TF-WI-0166: TCP advertised send-window update contract

## Required behavior

Connections retain `SND.WND`, `SND.WL1`, and `SND.WL2`. Handshake packets seed
them, and later acceptable ACKs update them only when the segment sequence is
newer, or when its sequence is equal and acknowledgment is not older. Ordering
uses TCP serial arithmetic across 32-bit wraparound.

## Evidence

The production-direct test executes `TCP4-CONNECTION-RECEIVE` with a duplicate
ACK that reopens the peer window and proves the receive path installs the new
`SND.WND` before flushing queued data. Removing the receive-path
`TCP-UPDATE-SEND-WINDOW` call is a rejected mutant. Window scaling is not
implemented. Direct WL1/WL2 tests additionally reject stale tuples, accept
32-bit sequence wraparound, and kill an unconditional-update mutant. Peer
interoperability remains guest/network validation.
