# TF-WI-0090 — EHCI QH 关联 qTD 回收

- **基线标记：** `TF-occ-c96095813fbfb091aa8fb9bd`
- **代码事实源：** `Lambda64/drivers/usb/ehci-intel.lisp:165`
- **风险：** high
- **要求测试层：** host、hardware

## 目标与实现

删除设备或 bulk endpoint 时，调用方已等待异步 doorbell 确认控制器停止访问队列。
`free-qh` 现在沿 QH 的 qTD 链遍历，逐项从 `pending-qtds` 移除并调用已有
`free-qtd`，最后释放 QH，避免 DMA 缓冲和 qTD 元数据泄漏。

## 先测试证据

`Lambda64/tests/host/test-drivers-usb-ehci-free-qtd.sh` 检查链遍历、pending 列表
清理和 `free-qtd` 调用，并确认删除回收调用的突变会被拒绝。
