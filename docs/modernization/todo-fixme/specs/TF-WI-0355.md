# TF-WI-0355: Resolve interpreted-function callee discovery

## Scope

`list-callees` currently derives callees from compiled function reference
constants. The baseline requirement calls out interpreted functions, whose
call bodies are not represented by the compiled constant-pool scan.

## Current boundary

Supporting interpreted functions requires a stable function-body traversal and
semantics for arbitrary funcallable instances. No cold-image or integration
fixture currently proves those semantics, so the marker remains active rather
than being replaced by a source-only claim.

## Required evidence

Add host, cold-image, and integration tests for interpreted lambdas and custom
funcallable targets, then remove the marker only after both paths agree.
