# TF-WI-0194 — SIMD 多立即数的嵌套分派

- **基线标记：** `TF-occ-814982628abfef5fc72035ba`
- **代码事实源：** `Lambda64/runtime/simd-arm64.lisp:252-286`
- **风险：** high
- **要求测试层：** host、codegen、cold-image

## 目标

`define-op` 为每个 immediate 参数生成一层 `ECASE`，并递归生成剩余 immediate 的
嵌套分派。每次递归都会将已消费的类型置为 `NIL`，避免重复选择同一参数；单立即数
操作的既有展开保持不变。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-simd-nested-immediates.sh`，检查生产宏包含递归
立即数分派、`immediate-max` 范围和终止调用；变异负例移除立即数位置选择，必须被
测试拒绝。

实现前宏只处理第一个 immediate，并留下 `Nested switches` FIXME；测试会拒绝该状态。

## 验收标准

1. 多 immediate 操作生成完整嵌套 `ECASE`，每个值均覆盖合法范围。
2. 已消费 immediate 不会在递归层重复分派。
3. 没有 immediate 时直接调用内部实现，既有单 immediate 行为保持兼容。
4. codegen 与 cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
