# TF-WI-0261: Define early physical mapping call boundary

`map-physical-memory-early` is reserved for boot-time callers that execute
before pager RPC is available. The function currently relies on its callers to
provide that phase guarantee; adding a runtime phase probe would introduce a
new boot-order dependency. Callers must therefore remain limited to ACPI, PCI,
and CPU early initialization paths.

Verification: `Lambda64/tests/host/test-supervisor-pager-boundaries.sh`.
