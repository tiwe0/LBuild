# TF-WI-0454 — x86-64 interrupt dispatch call form

The common interrupt path currently calls through the handler entry register.
Changing it to a direct named call requires assembler and relocation support
while preserving the interrupt frame and GC-safe calling convention; retain
the marker until those codegen and cold-image tests exist.

## Evidence (2026-09-01)

The handler is loaded from the runtime FREF in `r13` at cold-image build time; it is not a statically named function. The current `lea64` plus indirect `call rax` sequence is therefore required for dynamic handler replacement. A direct named call would target the wrong symbol unless the cold generator first materializes a stable per-handler symbol and relocation entry. The marker remains active pending that infrastructure and relocation tests.
