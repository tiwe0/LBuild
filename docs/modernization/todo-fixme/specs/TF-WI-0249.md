# TF-WI-0249 — Debug log ring byte update

- **基线标记：** `TF-occ-801cb02e01608a593c70248d`
- **代码事实源：** `Lambda64/supervisor/debug.lisp:74`

## 要求

共享 supervisor 日志环的单字节写入必须在关闭本地中断后取得独立的
`*supervisor-log-buffer-lock*`。该锁不能复用 UART 锁，因为伪流回调随后会
取得 UART 锁。锁初始化为 `:unlocked`；锁内仅访问 wired 日志缓冲区。

## 验收

`Lambda64/tests/host/test-supervisor-debug-log-lock.sh` 检查锁存在、初始化和
字节写入路径，并通过移除锁的 mutation run。
