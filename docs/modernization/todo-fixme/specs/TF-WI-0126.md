# TF-WI-0126: File-cache stream sequence read contract

## Scope

This specification closes the sequence-read requirement at
`Lambda64/file/cache.lisp:104`. It preserves the byte-read semantics while
allowing callers to fill a selected destination interval block by block.

## Required behavior

- The method honors destination `start`/`end`, reads only up to logical EOF,
  and returns the first destination index not filled.
- It spans cache blocks correctly, loads a new block only when necessary, and
  updates the stream position by exactly the number of bytes copied.
- A short read leaves destination elements after the returned index unchanged.
  An EOF or empty range performs no I/O and returns `start`.
- Switching cache blocks flushes any dirty current block before replacement, so
  an intervening read cannot lose prior writes.
- An invalid `start`/`end` interval signals before it can flush or load a cache
  block.

## Acceptance evidence

`Lambda64/tests/host/test-file-cache-sequences.sh` must cover a three-block
read, nonzero destination bounds, short reads at EOF, unchanged suffixes, and
empty-range behavior. The focused test and `make test-fast` are required
before this work item may be verified.
