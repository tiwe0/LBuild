# TF-WI-0094: EHCI bulk qTD dequeue protocol

## Current boundary

The baseline marker at `Lambda64/drivers/usb/ehci-intel.lisp:636` remains an explicit
implementation boundary. bulk-dequeue-buf unlinks a qTD but does not implement the EHCI queue-stop protocol. A safe implementation needs controller quiescence and hardware-level ordering evidence.

## Required evidence

Add host and hardware-backed regression coverage for the success, ordering,
and failure paths, then remove the marker only after the implementation and
controller behavior are verified together.
