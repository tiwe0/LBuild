# Without-footholds fast path

`without-footholds` only writes `thread-allow-with-footholds` when the prior
value is true. The disabled path therefore avoids an unnecessary slot write,
while the enabled path still restores the original value during unwind.

The host contract fixture checks both state transitions and mutates the
conditional guards to ensure the fast-path contract remains explicit.
