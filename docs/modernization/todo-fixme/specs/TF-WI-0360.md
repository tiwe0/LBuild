# TF-WI-0360: Preserve pending footholds across continuation resume

## Scope

`%resume-delimited-continuation-1` reenables footholds on the resumed stack
before returning to the function that originally aborted. The resume path may
carry multiple values in registers, so running pending footholds inline can
clobber the continuation result.

## Current boundary

Pending footholds remain deferred across continuation resume. A subsequent
supervisor safepoint owns queue execution after values are preserved. The
source comment and host contract make this ordering explicit; cold-image and
integration tests for queued footholds during resume are still missing.

## Required evidence

Add host, cold-image, and integration tests covering zero, one, and multiple
resume values with a queued foothold, including ordering and value retention.
Remove the source marker only after those paths agree.
