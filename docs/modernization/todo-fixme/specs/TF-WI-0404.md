# TF-WI-0404 — standard readtable 与当前 readtable 分离

- **基线标记：** `TF-occ-e89d918385a992d64177b95f`
- **代码事实源：** `Lambda64/system/reader.lisp:17-32,1060-1068`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

标准 reader 宏初始化完成后，默认 `*readtable*` 必须通过 `copy-readtable nil` 获得
独立副本。修改当前 readtable 不应回写 `*standard-readtable*`；显式请求标准表仍
返回标准定义。

## 先测试证据

新增 `Lambda64/tests/host/test-system-reader-standard-copy.sh`，检查初始化顺序和
标准表复制调用，并确认移除复制调用的变异会被拒绝。

## 验收标准

1. 标准 readtable 初始化后再复制为默认当前表。
2. 默认表与标准表不共享 base/extended character 存储。
3. `copy-readtable nil` 的既有标准表语义保持不变。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
