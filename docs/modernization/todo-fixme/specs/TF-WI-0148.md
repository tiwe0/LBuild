# TF-WI-0148: TGSI declaration qualifier contract

## Scope

This specification resolves the declaration-validation gap in
`Lambda64/gui/virgl/tgsi.lisp`. It covers the assembler's existing declaration
files plus TGSI dimension, array, semantic, interpolation, interpolation
location, and invariant syntax.

## Required behavior

The declaration register is `(file first &optional last)`. Both indices are
unsigned 32-bit integers and `last` must not precede `first`. Supported
qualifiers, in their TGSI text order, are:

1. `(:dimension index)`, emitted as the first register bracket;
2. `(:array id)`, where `id` is an unsigned 32-bit value, emitted as
   `ARRAY(id)`;
3. a semantic keyword or `(semantic index)`;
4. one of `:constant`, `:linear`, `:perspective`, or `:color`;
5. one of `:center`, `:centroid`, or `:sample`, only after interpolation;
6. `:invariant`.

Unknown, duplicate, malformed, or misplaced qualifiers fail before text is
returned. Mesa's text grammar does not accept semantic or interpolation
qualifiers on vertex inputs, so the assembler rejects those combinations.
Legacy forms such as `(:in 0) :color :color` retain their exact output.

Token accounting follows the binary TGSI representation rather than the number
of textual comma clauses: dimension, array, semantic, and interpolation each
add one token; interpolation location shares the interpolation token; invariant
is stored in the declaration token.

## Test-before evidence

Before implementation,
`Lambda64/tests/host/test-virgl-tgsi-parser.sh` failed on the first structured
declaration because the old loop required every qualifier to be a keyword:
`(:DIMENSION 2) ... is not of type KEYWORD`. The old implementation also
accepted reversed ranges and arbitrary keyword qualifiers, and over-counted
token fields that share a declaration token.

## Acceptance evidence

The focused host test loads the real assembler and verifies legacy output,
dimension/range output, unsigned array-identifier and indexed-semantic formatting, interpolation
and invariant order, exact token counts, and rejection of reversed ranges,
unknown qualifiers, duplicate semantics, invalid vertex-input qualifiers, and
out-of-range array identifiers.

The focused host test, `make lisp-style-check`, and a whitespace-clean diff are
required for this slice. The ledger also requires a guest virgl shader-creation
test. No guest/GPU evidence is recorded here, so this item must not be marked
verified yet.
