# TF-WI-0054: keyword rest and count lowering boundary

## Scope

The keyword-argument lowering pass in `Lambda64/compiler/keyword-arguments.lisp`
currently synthesizes lexical `&COUNT` and dynamic-extent `&REST` arguments when
keyword processing is enabled.

## Current boundary

The pass still consumes these arguments through the lambda-information
structures rather than lowering special `&REST`/`&COUNT` forms to ordinary
lexicals first. Changing that representation can affect argument-count checks,
unknown-key handling, and dynamic-extent lifetime, so the marker remains active.

## Required evidence

Add compiler and host tests covering required/optional/keyword/rest/count
combinations, `&ALLOW-OTHER-KEYS`, and dynamic-extent cleanup before removing the
marker.
