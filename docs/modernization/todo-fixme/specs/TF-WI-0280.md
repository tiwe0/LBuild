# TF-WI-0280: Atomic snapshot-inhibition nesting contract

## Scope

This item defines balanced concurrent updates of the snapshot-inhibition count.

## Required behavior

All dynamic inhibition entry and exit updates pass through
`SNAPSHOT-ADJUST-INHIBIT`, which uses `%ATOMIC-FIXNUM-ADD-SYMBOL`. The helper
returns the new count and detects an unbalanced decrement, restoring the prior
count before reporting the invariant violation. `UNWIND-PROTECT` guarantees a
matching release when the protected callback exits non-locally.

## Test-before evidence

The focused test reported the stale atomic-update marker. The source already
used the low-level atomic primitive directly, but had no centralized balance or
underflow contract.

## Acceptance evidence

The executable host regression verifies atomic increment/decrement and that an
underflow attempt restores zero. Multi-CPU nesting and retry interaction remain
guest scheduler validation.
