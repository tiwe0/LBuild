# TF-WI-0180 — ARM64 `SQRT` 双精度槽位直接加载

- **基线标记：** `TF-occ-99797739ec780cc3f040ee35`
- **代码事实源：** `Lambda64/runtime/float-arm64.lisp:114-121`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 目标

双精度平方根入口直接以 FP 寄存器类别的 `LDR D0` 读取对象槽位，再执行 `FSQRT`，
移除通用寄存器与 `FMOV` 中转及对应 FIXME。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-float-arm64-direct-loads.sh`，检查 `SQRT` 路径
保留直接 `LDR D0` 契约；将其变回通用寄存器加载的变异必须被拒绝。实现前测试因缺少
直接 FP 加载契约而失败。

## 验收标准

1. `%%double-float-sqrt` 直接加载 `D0` 后执行 `FSQRT`。
2. 读取偏移和 64 位槽位语义保持不变。
3. 结果装箱与尾调用约定不变。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。

```sh
bash -n Lambda64/tests/host/test-runtime-float-arm64-direct-loads.sh
bash Lambda64/tests/host/test-runtime-float-arm64-direct-loads.sh
```
