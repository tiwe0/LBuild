# TF-WI-0426 — Unifont 缺失字符占位字形

- **基线标记：** `TF-occ-958f61b39d52dab2e7c0eeb7`
- **代码事实源：** `Lambda64/system/unifont.lisp:30`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标与实现

对于不在内置 Unifont BMP 数据表中的平面 0 字符，`map-unifont-2d` 现在生成并缓存
一个 16×8 的空白 glyph，而不是返回 NIL。已有 glyph 仍使用原始 displaced backing
storage；缓存行为和非平面 0 过滤保持不变。

## 先测试证据

`Lambda64/tests/host/test-system-unifont-missing-glyph.sh` 检查缺失分支的空白数组
及缓存写入，并确认恢复直接返回 NIL 的突变会被拒绝。
