# TF-WI-0219: Define ARM64 WFE and SEV spin-wait boundary

## Scope

Close the WFE/SEV TODOs in `Lambda64/supervisor/arm64/interrupts.lisp` and
`arm64/cpu.lisp` without changing interrupt or scheduling semantics.

## Contract

`cpu-relax` remains an ARM64 `YIELD` hint. The quiesce counter loop also keeps
its active polling behavior because the current IPI path does not issue a
matching `SEV` for every counter decrement. Replacing either path with `WFE`
without that wakeup protocol could sleep indefinitely and prevent world-stop
completion. A future WFE optimization must add and verify the paired SEV
publication protocol first.

## Verification

`Lambda64/tests/host/test-supervisor-arm64-wfe-contract.sh` checks removal of
both stale markers and preservation of the YIELD/quiesce wakeup contract.
