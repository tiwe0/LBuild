# TF-WI-0256: Define supervisor entry reboot shim boundary

## Scope

Close the entry-module placement FIXME in `Lambda64/supervisor/entry.lisp`.

## Contract

The bootloader invokes `reboot` from the entry module before supervisor
subsystems are fully initialized. The shim therefore remains here as a narrow
compatibility boundary and delegates to the existing disk/snapshot sync and
`platform-reboot` lifecycle. Moving it safely requires a stable platform
reboot hook with equivalent early-boot availability.

## Verification

`Lambda64/tests/host/test-supervisor-entry-reboot-boundary.sh` checks marker
removal and the documented shim/platform reboot boundary.
