# TF-WI-0203: ACPI RSDP OEMID wired string decoding

The ACPI RSDP parser now stores the fixed six-byte OEMID as a six-character
wired string. Each byte is converted with `code-char` into a fixed slot; no
resizing or vector-of-byte representation is used.

`Lambda64/tests/host/test-supervisor-acpi-oemid-string.sh` verifies the wired
string constructor, fixed length, per-byte character conversion, and rejects a
mutation restoring the old wired byte-vector representation. Full ACPI
cold-image/integration execution is not recorded by this focused fixture.
