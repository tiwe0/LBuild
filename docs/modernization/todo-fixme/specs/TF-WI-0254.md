# TF-WI-0254: DMA buffer allocation failure condition

## Scope

`alloc-sg-vec` now signals the inspectable `dma-buffer-allocation-error`
condition when `ERRORP` is true and physical page allocation fails.

## Contract

The condition is an `error` and `storage-condition` subtype and exposes the
requested length, contiguous request, and 32-bit-only request through readers.
`ERRORP` false remains a non-signalling probe and returns NIL. Both contiguous
and non-contiguous allocation paths use the same condition and preserve the
existing cleanup behavior.

## Evidence

`Lambda64/tests/host/test-supervisor-dma-buffer-errors.sh` checks the condition,
readers, both signalling paths, package exports, and the retained non-signalling
path.
