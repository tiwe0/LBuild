# TF-WI-0309: Define x86 early console configuration boundary

## Scope

`Lambda64/supervisor/x86-64/platform.lisp:initialize-platform-early-console`
currently initializes the debug serial port before bootloader configuration is
available.

## Contract

Early x86 boot keeps the existing PC-compatible COM1 profile (I/O base `0x3F8`,
IRQ argument `0`, register stride `4`, and `115200` baud). These values are an
explicit platform boundary, not runtime-discovered settings. A future
boot-configuration API may provide the port, IRQ, stride, and baud; until that
API is defined and consumed by all early-console paths, changing the defaults
would risk breaking headless/QEMU bring-up.

## Verification

`Lambda64/tests/host/test-supervisor-x86-platform-console-contract.sh` checks
that the source retains the fixed profile, documents the configuration seam,
and does not reintroduce TODO/FIXME markers.
