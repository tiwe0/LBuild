# TF-WI-0367: ARM64 load/store immediate register width decoding

## Scope

This specification closes the register-width FIXME in
`Lambda64/system/disassemble-arm64.lisp` for load/store immediate decoding.
The destination register must reflect the AArch64 encoding: W registers for
byte, halfword, and ordinary word operations; X registers for doubleword,
`LDRSW`, and 64-bit sign-extending forms. SIMD/FP decoding remains unchanged.

## Required behavior

For integer load/store immediate instructions, decode `Rt` as `decode-gp32`
for 32-bit destinations and `decode-gp64` for 64-bit destinations. In
particular, `size = 3` and `opc = 2` sign-extending forms (including `LDRSW`) select X
registers; byte/halfword/word forms otherwise select W registers.

## Acceptance evidence

`Lambda64/tests/host/test-system-disassemble-arm64-registers.sh` checks the
source-level decode contract and runs a mutation-aware guard that replaces the
width condition with the former all-`X` behavior; the mutation must fail.
The focused script passes against the implemented source and rejects the
mutated source. Cold-image and integration execution are not recorded here.
