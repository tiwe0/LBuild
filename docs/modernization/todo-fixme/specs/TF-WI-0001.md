# TF-WI-0001: Fancy REPL completion tokenization contract

## Scope

This specification defines the lexical boundary used by
`mezzano.line-editor:compute-completions` in
`Lambda64/applications/fancy-repl.lisp`. It resolves the baseline directive at
the former line 25 without changing the reader or line editor.

## Required behavior

- Completion tokenization uses the active readtable through
  `readtable-syntax-type` and `get-macro-character`.
- Whitespace and terminating macro characters delimit a token. A macro
  character whose current readtable entry is non-terminating remains part of
  the token.
- A single escape consumes the following character as token text even when
  that character would otherwise terminate the token. A multiple-escape pair
  keeps every enclosed character inside the token. A trailing unmatched escape
  is bounded safely at the end of the edit buffer.
- Only an unescaped colon is interpreted as a package marker. Colons protected
  by either single or multiple escapes remain symbol-name text.
- Completion is disabled when the cursor is inside a conventional string whose
  `#\"` delimiter is a terminating macro character in the active readtable.
  Escaped quotes do not close that string.
- Completion is disabled from a terminating `#\;` through the end of its line
  and resumes after the newline. This is deliberately a line-comment contract;
  dispatch-reader comments such as `#|...|#` are not guessed from character
  spelling because their meaning depends on the active dispatch table.
- Outside those disabled regions, the helper returns the complete token around
  the cursor so the existing package and symbol candidate logic remains in
  charge of candidate generation and insertion.

## Acceptance evidence

`Lambda64/tests/host/test-fancy-repl-completion-lexer.sh` extracts and executes
the pure lexer helpers with a controlled readtable facade. It must cover
terminating and non-terminating macros, single and multiple escapes, string and
line-comment suppression, token-start cursor positions, escaped package
markers, and resumption after a closing delimiter or newline.
