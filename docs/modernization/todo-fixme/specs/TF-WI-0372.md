# TF-WI-0372 — x86-64 `MOVHLPS`/`MOVLPS` 解码

- **基线标记：** `TF-occ-17d81b8c81e1edbd79b03080`
- **代码事实源：** `Lambda64/system/disassemble-x86-64.lisp:620-621`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

在 SSE opcode `0F 12 /r` 中，寄存器 R/M 操作数应解码为 `MOVHLPS`；内存
R/M 操作数的同一编码实际表示 `MOVLPS`。目标寄存器和寻址操作数的解码方式
保持现有 x86-64 规则不变。

## 先测试证据

新增 `Lambda64/tests/host/test-system-disassemble-movhlps.sh`。测试验证专用
decoder 同时包含寄存器和内存分支，并通过将 R/M 分类条件变异为恒真来确认旧的
“内存也解码成 MOVHLPS”实现会被拒绝。

## 验收标准

1. `mod=11` 的 R/M 字段解码为两个 XMM 寄存器和 `MOVHLPS`。
2. `mod!=11` 的 R/M 字段保留有效地址并解码为 `MOVLPS`。
3. 其他 SSE 解码路径继续保持原有行为。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
