# TF-WI-0124 — virtio-net 接收包长度

- **基线标记：** `TF-occ-4865fc1bd02de27ba71e7c3b`
- **代码事实源：** `Lambda64/drivers/virtio-net.lisp:104-139`
- **风险：** high
- **要求测试层：** host、hardware

## 目标

接收路径依据 used descriptor 的 `len - +virtio-net-hdr-size+` 计算真实 payload 长度，
在 MTU 范围内复制并裁剪数据包，同时按真实长度更新接收字节计数；非法长度立即拒绝，
避免把固定 MTU 或负长度暴露给网络层。

## 先测试证据

新增 `Lambda64/tests/host/test-driver-virtio-net-rx-packet-size.sh`，检查 payload 长度
计算、边界校验、`adjust-array` 裁剪和计数器更新；变异负例移除裁剪步骤，必须被测试
拒绝。实现前测试因缺少这些契约而失败。

## 验收标准

1. 网络层收到的 packet 长度等于 descriptor payload 长度，而非固定 MTU。
2. 接收字节统计等于实际 payload 长度。
3. 负长度或超过 MTU 的 descriptor 不会越界写入。
4. 在 `hardware-virtio-net` 资源可用时完成真实设备回归；当前工作项保持 `active`。
