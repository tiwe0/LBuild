# TF-WI-0429: XP fixed floating-point FORMAT directive

## Scope

This work item closes the baseline marker in
`Lambda64/system/xp-format.lisp`. The late XP formatter now delegates `~F`
rendering to the matching `MEZZANO.FORMAT::format-fixed-float` implementation rather than
maintaining a divergent partial float printer.

## Required behavior

Fixed decimal rendering through the XP formatter honors precision, scale, width, padding, overflow characters, and explicit signs, including the non-real fallback. The delegated writer receives the XP character stream directly, so
layout buffering remains under XP control.

## Acceptance evidence

`Lambda64/tests/host/test-system-xp-format-float-delegation.sh` checks the
production `format-float` wrapper, its directive handler's default parameter
vector, and the `params, atsign, colon` forwarding order. It executes the
wrapper with the repository's early FORMAT implementation, covers successful
output, width/precision or sign/padding boundaries, and the non-real fallback
where applicable. It rejects mutations of the shared renderer, every handler
parameter vector, and every handler modifier order; it also locks XP's Gray
character-stream write delegation.

The old implementation fails the focused test because it calls the undefined
`MEZZANO.INTERNALS::WRITE-FLOAT` host stub and does not apply the directive
parameters. Host verification is recorded; cold-image and integration coverage
remain outstanding, so this specification remains `active`.
