# TF-WI-0429: ARM64 assembler registry synchronization

## Change

The ARM64 instruction assembler registry now uses synchronized hash-table mode.
Instruction definitions can be loaded while compiler workers read the registry;
synchronization prevents readers from observing a resize/update in progress.
GC invariant key enforcement remains enabled.
