# TF-WI-0351 — 统一 `COERCE` 与其 compiler macro

- **基线标记：** `TF-occ-1219ec64f77942582de1fa65`
- **代码事实源：** `Lambda64/system/coerce.lisp:40-108`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`COERCE` 的实际转换分支集中到 `%coerce-value`，而 compiler macro 在 result type 为常量时
只负责保存 object 的单次求值，并调用同一实现。该 helper 声明为 inline，保留编译期内联
机会；同时，compiler macro 现在与运行时函数一致：当 object 已满足目标类型时直接返回
原对象，而不是意外复制 list 或 vector。

## 先测试证据

`Lambda64/tests/host/test-system-coerce-dedup.sh` 在旧实现上失败：

```text
compiler macro COERCE copied a matching list
```

回归覆盖 list/vector 的 identity 路径，以及 list 到 vector 的实际转换结果与运行时
`COERCE` 相同。mutation 负例移除 compiler macro 的 `typep` identity 分支，确保两条
执行路径不会再次产生不一致的复制行为。
