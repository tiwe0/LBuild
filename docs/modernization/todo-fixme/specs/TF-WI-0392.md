# TF-WI-0392: GC worker finalizer error boundary

## Change

The GC worker delegates callback isolation to `run-finalizers`, which catches
and reports each finalizer condition and clears its weak pointer. GC-cycle
failures remain fatal to preserve heap-integrity guarantees; they are not
swallowed by the worker. The former catch/report TODO is replaced with this
explicit boundary contract.
