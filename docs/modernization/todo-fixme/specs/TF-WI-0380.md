# TF-WI-0380: Compiler macro expansion in LLF lowering

## Scope

This work item adds compiler-macro processing to top-level value lowering while
preserving ordinary macro and symbol-macro expansion.

## Required behavior

`compile-top-level-form-for-value` repeatedly performs ordinary macro expansion
and `mezzano.compiler::compiler-macroexpand-1` until neither changes the form.
The active lexical environment participates in both operations, including
inline/notinline policy. A compiler macro can therefore reduce a call before
LLF funcall lowering; rejected expansions retain the original call.

## Acceptance evidence

The focused host test invokes the production lowering function with a controlled
compiler-macro expander and verifies that `(compiler-macro-probe)` becomes the
literal `42` LLF command rather than an ordinary call. The pre-change `HEAD`
source fails the focused contract gate with exit 1; the implemented source
passes.

Cold-image code generation and integration execution remain unrecorded, so this
specification remains `active`.
