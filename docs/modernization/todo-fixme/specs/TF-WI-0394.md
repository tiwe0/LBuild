# Verify boxed slots in instance heap layouts

`verify-object` now mirrors the collector's bit-vector layout handling for
instances and funcallable instances. For each `1` bit it verifies the boxed
slot at object word `i + 1` (the object header occupies word zero); unboxed
slots are skipped. This keeps debug intergenerational-pointer validation
consistent with `scan-object-1` and avoids treating raw slot payloads as
references.

The focused host fixture checks source anchors, boxed-slot offsets, empty
layouts, and a mutation that removes the header offset.
