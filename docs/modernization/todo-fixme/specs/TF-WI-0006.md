# TF-WI-0006: ARM64 AdvSIMD unboxed type contract

## Scope

Unboxing crosses the generic SIMD IR boundary. Lane-specific information is
held by the instruction/header, while callers require the common boxed class
for all AdvSIMD values.

## Required behavior

- `ir:box-type` for `unbox-advsimd-instruction` returns exactly
  `mezzano.simd:simd-pack`.
- The method remains independent of a concrete lane subtype.
- No code-generation or runtime representation changes are implied.

## Acceptance evidence

`Lambda64/tests/host/test-compiler-arm64-box-type.sh` checks the method body
and rejects a mutation replacing the shared SIMD pack type with `nil`.
Guest/codegen and cold-image evidence remain required by the work-item ledger.
