# TF-WI-0061 — `ERROR` forms keep an explicit unreachable terminator

- **基线标记：** `TF-occ-a5fd2b03c5d6002a8bff07a3`
- **代码事实源：** `Lambda64/compiler/pass1.lisp:339-355`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 边界

`pass1-function-form` lowers a top-level `ERROR` call to an `ast-progn` containing
that call followed by `sys.int::%%unreachable`.  Although `ERROR` does not return,
the explicit terminator closes the AST path for subsequent control-flow passes and
keeps code generation deterministic.  Consumers must not infer this property from
the function name alone.

The implementation is intentionally unchanged; the former FIXME was replaced by
this rationale.  A future control-flow representation may remove the synthetic tail
only after equivalent terminator semantics are proven at all required test levels.
