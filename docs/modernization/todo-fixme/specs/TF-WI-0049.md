# TF-WI-0049 — cross-compiler complex short-float promotion

- **Baseline marker:** `TF-occ-6ca7f1e8078d04a9d0592223`
- **Code source of truth:** `Lambda64/compiler/cross-compile.lisp:730`
- **Risk:** critical
- **Required test levels:** host, codegen, cold-image

## Current boundary

When either component passed to `mezzano.compiler:complex` is a target
`cross-short-float`, the current implementation requires both components to be
already converted and otherwise asserts.  The target's half-precision format,
rounding, overflow, NaN, and signed-zero rules are not specified here, so
delegating to host `cl:complex` or guessing a conversion would produce
non-portable constants.

## Required completion evidence

1. Define conversion and promotion rules for mixed target/host components,
   including exceptional values and exact serialized bit patterns.
2. Add host tests for mixed components and boundary values, with a mutation
   case that detects accidental host-float widening.
3. Verify codegen and cold-image serialization against the target
   `(complex short-float)` layout.

The marker remains `active` pending that numeric-format and serialization
evidence; the existing assertion is the safer behavior than silent widening.
