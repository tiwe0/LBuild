# TF-WI-0250 — Debug log buffered flush

- **基线标记：** `TF-occ-9a3dd9abfd1b61352c0b1187`
- **代码事实源：** `Lambda64/supervisor/debug.lisp:199`

## 要求

刷新动态缓冲区时，必须在关闭本地中断后持有
`*supervisor-log-buffer-lock*`，使一条记录对其他 CPU 保持连续。刷新使用
不再尝试取得同一锁的内部字节更新 helper，避免锁递归；伪流回调在释放该锁后
执行。

## 验收

`Lambda64/tests/host/test-supervisor-debug-log-lock.sh` 同时验证 byte writer 与
flush 的锁保护及非递归 helper，并通过 mutation run。
