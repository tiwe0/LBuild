# TF-WI-0174: Wired function post-GC expansion contract

## Scope

This contract resolves the corresponding baseline directive in
`Lambda64/runtime/allocate.lisp` without changing its public allocator API.

## Required behavior

The low-free-space path invokes the shared function-area expander for both normal and wired allocations; wired allocation is no longer excluded after collection.

## Test-before evidence

Before implementation, `bash Lambda64/tests/host/test-runtime-allocate-contracts.sh`
exited with status 1 at the first missing production form,
`update-freelist-card-offsets`.

## Acceptance evidence

The focused source contract verifies the wired-only exclusion is absent and wired expansion uses the dedicated downward publication helper.

The focused fixture extracts and executes production forms while replacing only
Mezzano memory, tag, and atomic primitives with deterministic host facades. It
also rejects any remaining TODO/FIXME marker in the owned production file.

Cold-image boot, concurrent SMP allocation, pager fault handling, and long-run
GC behavior have not been exercised by this host run. This item remains active
until those integration requirements are verified in a guest image.
