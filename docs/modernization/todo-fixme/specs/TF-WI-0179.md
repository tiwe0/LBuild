# TF-WI-0179 — ARM64 双精度槽位直接加载到 FP 寄存器

- **基线标记：** `TF-occ-6ff1a9d54d858808361c2feb`
- **代码事实源：** `Lambda64/runtime/float-arm64.lisp:43-49`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 目标

双精度运算入口直接使用支持 FP 寄存器类别的 `LDR`，将对象槽位加载到 `D0/D1`，不再
经由通用寄存器和 `FMOV` 中转。这样消除旧 FIXME，同时保持对象槽位的 64 位位模式
不变。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-float-arm64-direct-loads.sh`，检查算术宏使用
`LDR D0/D1`，并验证删除任一直接加载的变异会被拒绝。实现前测试因缺少直接 FP 加载
契约而失败。

## 验收标准

1. 四个双精度算术入口均直接加载 `D0/D1`。
2. 直接加载的偏移和槽位宽度保持 64 位。
3. 既有装箱、运算和尾调用约定不变。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
