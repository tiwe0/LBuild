# TF-WI-0413 — `(setf compiler-macro-function)` 的 environment 策略

- **基线标记：** `TF-occ-e338b2734bb697267be94412`
- **代码事实源：** `Lambda64/system/runtime-support.lisp:226-240`
- **风险：** medium
- **要求测试层：** host、cold-image、integration

## 目标

`compiler-macro-function` 可利用 environment 查询局部 function binding 对 compiler macro
可见性的遮蔽关系；但对非空 environment 的 setter 调用没有 Common Lisp 定义的语义。
Lambda64 将该情况统一为 `simple-program-error`，只允许更新全局 `function-info` 中的
compiler macro definition，且失败请求不会污染全局 binding。

## 先测试证据

`Lambda64/tests/host/test-system-runtime-support-macro-environment.sh` 在旧实现上失败：

```text
non-global macro definition did not signal PROGRAM-ERROR
```

同一 host 回归同时覆盖两个标准 accessor：全局 compiler macro 的设置与清除、非空
environment 的 `program-error`，以及被拒绝请求后原全局 compiler macro 未变。其 mutation
负例将专用 condition 替换为普通 error，验证策略约束实际生效。

bash Lambda64/tests/host/test-system-runtime-support-macro-environment.sh
