# TF-WI-0039: Close x86 double-float equality condition contract

## Scope

Baseline occurrence `TF-occ-7f3475629240cdc92e73c7ad` at
`Lambda64/compiler/backend/x86-64/number.lisp:1506` documents the conditions
needed by `sys.int::%%double-float-=`.

## Contract

`ucomisd` sets PF for unordered (NaN) operands and ZF for unordered or equal
operands. The lowering starts with true, clears it on PF, and clears it on NE
(`cmov64p` followed by `cmov64ne`), yielding true only for ordered equality.
Both operands and the result retain the existing double-float boxing/unboxing
conventions.

## Verification

`Lambda64/tests/host/test-compiler-x86-float-equality.sh` checks the lowering
anchors, executable NaN semantics, and rejects a mutation that removes the PF
guard.
