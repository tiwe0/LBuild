# TF-WI-0408 — `#C` complex reader 的 real 校验

- **基线标记：** `TF-occ-e2f73bbb256c50c95cd80494`
- **代码事实源：** `Lambda64/system/reader.lisp:762-779`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`#C` dispatch reader 应直接使用统一的 `realp` 谓词验证实部和虚部。运行时的
`realp` 已覆盖 fixnum、各种浮点和 bignum/ratio 等 real 类型，不需要为
`short-float` 添加交叉编译专用分支。

## 先测试证据

新增 `Lambda64/tests/host/test-system-reader-complex-real-check.sh`，检查两个分量
均使用 `realp`，并确认恢复 `short-float-p` 特判的变异会被拒绝。

## 验收标准

1. 合法 real 分量（含 short-float）继续构造 complex 值。
2. 非 real 分量继续报告明确的 invalid complex number 错误。
3. reader 不再依赖交叉编译环境下的短浮点特判。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
