# TF-WI-0311 — LOOP list iterator declaration compatibility

- **基线标记：** `TF-occ-d48f45de0328686ec7f04df7`
- **代码事实源：** `Lambda64/system/ansi-loop.lisp:154`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 决策

`*loop-list-data-type*` 保持为 `T`，而不是恢复为 `LIST`。LOOP 允许用户提供不透明的
`:BY` 步进函数；生成绑定上的 `LIST` 声明会成为编译器优化假设，可能改变 CAR/CDR
代码生成。保留无类型绑定维持现有行为，让 LOOP 的常规迭代语义处理步进结果。

源文件中的说明注释已取代 FIXME，明确记录兼容性边界。聚焦 host 合约测试锁定两个
绑定为 `T`，并确认把列表绑定收紧为 `LIST` 的变异会被拒绝。
