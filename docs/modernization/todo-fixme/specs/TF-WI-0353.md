# TF-WI-0353: Define cold-start documentation table weakness boundary

## Scope

Close the weak structured-key FIXME in `Lambda64/system/cold-start.lisp`.

## Contract

Function and compiler-macro documentation tables use structured package/name
keys, while the current weak-key hash-table contract only supports direct keys.
They therefore remain synchronized strong tables until dedicated SETF/CAS weak
tables are implemented; the existing SETF and variable tables remain weak.
