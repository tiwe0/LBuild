# TF-WI-0229 — ARM64 高精度计时器实现

- **基线标记：** `TF-occ-cc3df48fddab166499eb38b6`
- **代码事实源：** `Lambda64/supervisor/arm64/time.lisp:76-90`
- **风险：** critical
- **要求测试层：** host、cold-image、integration

## 目标

ARM64 平台的 `get-high-precision-timer` 使用架构计数器 `CNTVCT_EL0` 提供高精度
时间值，并通过 `ISB` 保证读取顺序。补充与 x86-64 等价的 API 契约文档，明确该值
可能在快照或计数器回绕时非单调，并由
`high-precision-time-units-to-internal-time-units` 转换为内部时间单位。

## 先测试证据

新增 `Lambda64/tests/host/test-supervisor-arm64-high-precision-timer.sh`，检查函数
文档、计数器读取和屏障指令，并确认移除契约文档的变异会被拒绝。

## 验收标准

1. 高精度计时器返回 `CNTVCT_EL0` 当前值，并在读取后执行 `ISB`。
2. 调用方可依据现有转换函数将计数器单位换算为内部时间单位。
3. 契约明确非单调与快照回绕语义，不改变现有运行时行为。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
