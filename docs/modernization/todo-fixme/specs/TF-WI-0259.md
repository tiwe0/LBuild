# TF-WI-0259: Define spinlock release ordering boundary

`release-place-spinlock` uses the CAS expansion because the ARM64 write form
does not yet provide release semantics. Replacing this with a plain write is
unsafe until the backend emits the required release barrier. Keep the CAS path
and revisit when ARM64 atomic ordering support is available.

Verification: `Lambda64/tests/host/test-supervisor-pager-boundaries.sh`.
