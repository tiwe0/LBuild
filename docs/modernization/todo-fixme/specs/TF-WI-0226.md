# TF-WI-0226: Define ARM64 FDT simple-bus range translation boundary

## Scope

Close the bare TODO in `register-fdt-simple-bus` for non-empty `ranges`
properties.

## Contract

A non-empty FDT `ranges` property requires translating child bus addresses into
the parent address space before MMIO probing. The current walker does not carry
translation context or expose a mapping API, so it deliberately ignores these
buses instead of registering devices at untranslated addresses. Supporting
arbitrary ranges requires extending the FDT walker and MMIO registration APIs.

## Verification

`Lambda64/tests/host/test-supervisor-arm64-platform-ranges-contract.sh` checks
marker removal and preservation of the translation-safety boundary.
