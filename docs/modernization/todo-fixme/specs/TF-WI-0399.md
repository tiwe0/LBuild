# TF-WI-0399: Large-byte representation inheritance boundary

`large-byte` currently provides the out-of-line representation for byte
specifiers while the package-local `byte` type predicate handles both forms.
Making it inherit from the built-in `byte` class would require reconciling the
local type definition and bootstrap ordering; retain the explicit predicate
boundary until that ABI is designed and tested.
