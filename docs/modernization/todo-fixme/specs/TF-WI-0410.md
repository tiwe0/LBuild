# TF-WI-0410 — `ROOM` allocated class 索引排序

- **基线标记：** `TF-occ-9308d3592bddf8d76b9a3704`
- **代码事实源：** `Lambda64/system/room.lisp:288-345`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`area-info` 在停止世界期间统计实例布局时，按 layout 对象地址维护
`allocated-classes`。已有类通过二分查找定位；新类按地址插入并移动现有
条目，使返回的类/计数对保持有序。用于统计的数组在进入 `walk-area` 前一次性
分配，停止世界期间只进行原地移动和计数更新，不触发扩容分配。

二分查找、步长为 2 的条目布局和原地 `replace` 插入，并确认移除地址键的变异
会被拒绝：

```sh
bash Lambda64/tests/host/test-system-room-allocated-classes.sh
```

## 验收标准

1. 相同 layout class 的计数仍合并到同一条目。
2. 新 class 按 `lisp-object-address` 升序插入，已有条目保持可二分查找。
3. `with-world-stopped` 回调不扩容、不分配；达到固定容量时报告明确错误。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
