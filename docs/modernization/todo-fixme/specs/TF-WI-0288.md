# TF-WI-0288: voluntary switch FPU save boundary

Voluntary context switches currently save the complete FPU state. Reducing
this to control registers is an ABI and architecture change and must preserve
lazy state, signal delivery, and both x86 and ARM64 paths; the marker remains
until those invariants have focused coverage.
