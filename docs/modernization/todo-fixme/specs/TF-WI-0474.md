# TF-WI-0474: Define x86 LAPIC timer divisor calibration boundary

## Scope

Close the divisor-selection TODO in `Lambda64/supervisor/x86-64/cpu.lisp`.

## Contract

LAPIC setup uses the fixed divide-by-16 encoding (`#x03`). Calibration runs
against that configuration and averages multiple ticks before publishing the
per-CPU rate. Dynamically changing the divisor would require atomically
reprogramming every active CPU timer and recalibrating in-flight deadlines, so
this optimization remains outside the current timer ABI.

## Verification

`Lambda64/tests/host/test-supervisor-x86-lapic-divisor-contract.sh` checks
marker removal, fixed divisor setup, and the calibration rationale.
