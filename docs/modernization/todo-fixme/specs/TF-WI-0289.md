# TF-WI-0289: thread final cleanup lock ordering boundary

`thread-final-cleanup` publishes the join event before acquiring the global
thread lock because `event-state` requires the lock to be released. The small
SMP visibility window is documented and intentionally retained until event
state publication and scheduler lock ordering can be redesigned together.
