# TF-WI-0477: Define boxed SIMD layout visibility boundary

## Scope

Close the backend boxing FIXME in `Lambda64/compiler/backend/passes.lisp`.

## Contract

The box/unbox elimination pass keeps a conservative visibility check before
rewriting a value whose representation may become observable. The check is
especially important for SIMD pairs with distinct layouts (for example,
`f32.4` versus `f64.2`); `simd-pack` remains excluded because it has no stable
pair-layout contract in this pass. This preserves the existing optimization
boundary without guessing at backend representation compatibility.

## Verification

`Lambda64/tests/host/test-compiler-box-unbox-layout-contract.sh` checks that
the FIXME is closed and that the conservative layout guard remains intact.
