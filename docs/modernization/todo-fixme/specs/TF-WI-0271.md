# TF-WI-0271: Sparse card-table snapshot-copy traversal contract

## Scope

This item covers runtime snapshot traversal of the mostly sparse card-table
virtual range.

## Required behavior

`MAP-SNAPSHOT-WIRED-PAGES` is the single range authority for wired heap, wired
function, and card-table pages. The card-table range must always use
`MAP-PTES :SPARSE T`, so absent page-table branches are not scanned or treated
as missing mappings.

## Test-before evidence

The focused test reported the former card-table sparseness marker and no shared
range traversal contract.

## Acceptance evidence

The host contract verifies that the production traversal contains the sparse
mode and that snapshot copying uses the shared walker. Guest timing and large
sparse address-space behavior remain integration evidence.
