# TF-WI-0424: GC finalizer error isolation

## Change

`run-finalizers` now catches and reports each finalizer condition through the
supervisor console, then clears that weak pointer in `unwind-protect`. A broken
finalizer no longer aborts the queue or leaves its callback reference retained.
