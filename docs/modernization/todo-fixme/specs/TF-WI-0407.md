# TF-WI-0407 — `#:` 非 intern 语义

- **基线标记：** `TF-occ-a875f6407196545281705f87`
- **代码事实源：** `Lambda64/system/reader.lisp:175-290,704-716`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`#:<name>` dispatch reader 必须生成 uninterned symbol，但读取名称时不能因为复用
keyword token 路径而把同名符号写入 `KEYWORD` package。普通 `:name` 和显式 `::`
路径继续保持原有 interning 语义。

## 先测试证据

新增 `Lambda64/tests/host/test-system-reader-uninterned-symbol.sh`，检查 `read-token`
提供关闭 keyword interning 的参数、`read-#-colon` 传入该参数，并从 token 字符串创建
uninterned symbol；去掉参数的变异必须被拒绝。

## 验收标准

1. 读取 `#:<name>` 返回新 symbol，且不会新增 `KEYWORD::<name>`。
2. 同一名称重复读取仍生成不同 symbol。
3. 普通 keyword 和 package marker 读取行为不变。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。

## 当前证据

```sh
bash -n Lambda64/tests/host/test-system-reader-uninterned-symbol.sh
bash Lambda64/tests/host/test-system-reader-uninterned-symbol.sh
```

image 与 integration 尚未运行。
