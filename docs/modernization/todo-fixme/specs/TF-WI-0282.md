# TF-WI-0282 — Ordered deferred store freelist

## Scope

Deferred store ranges are traversed during snapshot regeneration and release;
they therefore need the same ascending-start invariant as the main freelist.

## Implementation

`store-deferred-free` inserts entries by start address, merges both adjacent
neighbors when present, and rejects overlap instead of creating duplicate
metadata ranges.

## Acceptance evidence

`Lambda64/tests/host/test-supervisor-store-deferred-freelist.sh` checks the
production ordering/coalescing form and rejects a mutation removing the sorted
traversal boundary. Cold-image and integration evidence remain pending.
