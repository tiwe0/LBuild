# TF-WI-0471: Define virtio boot reinitialization detach boundary

## Scope

Close the device-removal notification TODO in `sup::initialize-virtio`.

## Contract

Virtio device objects retained from a previous boot are invalidated by their
boot epoch. During initialization, notifying their drivers would touch stale
transport state before the new FDT/PCI scan reconstructs the registry. Runtime
detach notifications therefore remain explicit through
`VIRTIO-DRIVER-DETACHED`; initialization resets the device lists without invoking
stale callbacks.

## Verification

`Lambda64/tests/host/test-supervisor-virtio-init-detach-contract.sh` checks
marker removal and preservation of the boot-epoch/stale-transport boundary.
