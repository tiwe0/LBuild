# TF-WI-0418: Atomic instance supersession publication

- **Status:** completed
- **Owner:** runtime
- **Scope:** `Lambda64/runtime/instance.lisp`
- **Risk:** concurrent class/layout transitions and GC interaction

## Change

`supersede-instance` now publishes obsolete headers with an atomic CAS while
holding the copied layout live. Already-obsolete instances install the
replacement via CAS on `layout-new-instance`; races retry from the current
layout instead of overwriting a concurrent replacement.

## Validation

- `Lambda64/tests/host/test-runtime-instance-supersede-atomic.sh`
- `make lisp-style-check`
- `make docs-check`

The host test is mutation-aware and verifies both publication CAS paths and
rooting of copied layouts before the header transition.
