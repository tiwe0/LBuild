# TF-WI-0044 — 常量传播中的 lambda 调用边界

- **基线标记：** `TF-occ-740d366bb2b33e0607721058`
- **代码事实源：** `Lambda64/compiler/constprop.lisp:9-12,367-389`
- **风险：** high
- **要求测试层：** host、codegen、cold-image

## 目标

常量传播只允许在调用目标为 `FUNCALL` 时把已知 lambda 值替换进调用参数。将 lambda
传播到任意函数可能改变函数身份、分配位置或副作用时序；非 `FUNCALL` 调用应保留
词法变量形式。普通常量和其他传播规则不变。

## 先测试证据

新增 `Lambda64/tests/host/test-compiler-constprop-lambda-call-guard.sh`，检查生产源的
动态调用上下文开关、`FUNCALL` 判定和拒绝路径；变异负例使所有调用都允许 lambda，
必须被测试拒绝。

实现前源码仅有 FIXME，缺少调用上下文保护；测试会拒绝该状态。

## 验收标准

1. `FUNCALL` 调用可继续传播 lambda。
2. 其他函数调用不会接收由词法变量传播而来的 lambda。
3. 变量使用计数和普通常量传播语义保持一致。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
