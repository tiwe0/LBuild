# TF-WI-0340 — Fast class hash table 弱键清理

- **基线标记：** `TF-occ-fc4ccd4185c3721f339f9625`
- **代码事实源：** `Lambda64/system/clos/fast-class-hash-table.lisp:9`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标与实现

每次更新 fast class hash table 前扫描其单项或向量存储，移除已经死亡的弱键；
向量槽使用 tombstone 并同步减少计数，单项存储则恢复为空表。读路径不修改表，
避免破坏并发读取契约。
