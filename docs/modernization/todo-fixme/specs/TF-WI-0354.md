# TF-WI-0354 — Block-map writable capability

## Scope

The `+block-map-writable+` capability in `Lambda64/system/data-types.lisp`
must be enforced when handling page faults. A write fault against a block
without this capability must not be reported as handled by the zero-fill fast
path.

## Implementation

`wait-for-page-fast-path` now rejects non-writable write faults before the
zero-fill mapping branch. Read faults and writable blocks retain the existing
mapping and GC write-barrier behavior.

## Acceptance evidence

`Lambda64/tests/host/test-supervisor-pager-writable-fast-path.sh` checks the
permission guard ordering and rejects a mutation that removes it. Cold-image
and guest integration evidence remain pending.
