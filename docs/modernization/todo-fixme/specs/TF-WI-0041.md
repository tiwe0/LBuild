# TF-WI-0041: Lower x86-64 instance predicates without fixed RAX

## Scope

`Lambda64/compiler/backend/x86-64/object.lisp:70`.

## Current boundary

The instance-or-funcallable-instance predicate uses AL/RAX as a fixed temporary for byte operations. Generalizing it requires allocated 8-bit preg conversion while preserving condition codes and GC liveness.

## Required evidence

Add codegen, cold-image, and host tests covering byte-register allocation and spill behavior before removing this marker.
