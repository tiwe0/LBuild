# TF-WI-0369: ARM64 register-offset register decoding

## Scope

Close the register-decode FIXME in
`Lambda64/system/disassemble-arm64.lisp` for register-offset load/store
instructions.  The decoded `Rt` must use the transfer width: integer W/X
registers follow the encoding, while SIMD/FP forms select B/H/S/D/Q from the
effective transfer scale.

## Required behavior

For integer forms, `size = 3` or `opc = 2` selects `decode-gp64`; all other
byte/halfword/word forms select `decode-gp32`.  SIMD/FP register-offset forms
map the effective scale to `decode-fp` type `:b`, `:h`, `:s`, `:d`, or `:q`.

## Acceptance evidence

`Lambda64/tests/host/test-system-disassemble-arm64-offset.sh` checks both the
effective address scale and register-width/type contracts.  Its mutation guard
reintroduces raw-size scaling and all-X integer decoding; the mutation must
fail.
