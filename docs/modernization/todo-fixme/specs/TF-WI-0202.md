# TF-WI-0202 — `(setf symbol-plist)` 的 property list 校验

- **基线标记：** `TF-occ-b6353176b4ff08fcb240b0a2`
- **代码事实源：** `Lambda64/runtime/symbol.lisp:208-231`
- **风险：** critical
- **要求测试层：** host、cold-image、integration

## 目标

`(setf symbol-plist)` 现在只接受 proper、偶数长度且非循环的 property list。校验在
hash-table 写入前完成，因此 atom、dotted list、奇数长度或循环 list 均不会把无法由
`getf`/`remprop` 安全遍历的值写入全局 symbol property 表。有效 property list 与
`nil` 清除行为保持不变。

## 先测试证据

`Lambda64/tests/host/test-runtime-symbol-plist-validation.sh` 在旧实现上失败：

```text
dotted list was accepted as a property list
```

回归覆盖有效的多 pair property list、atom、dotted、奇数长度与循环列表；每个无效
写入都必须报错并保留既有值。mutation 负例将 proper-list 终止判定翻转，确保有效
list 路径也受测试保护。
