# TF-WI-0018: Lower ARM64 integer memref CAS through SSA-safe CAS IR

## Scope

`Lambda64/compiler/backend/arm64/memory.lisp:79`.

## Current boundary

Integer memref accessors still use a bespoke arm64-cas-mem instruction because generic CAS mutates inputs. Convert only with SSA-safe operands and preserved boxing/ordering semantics; retain marker pending concurrent stress coverage.

## Required evidence

Add focused code-generation tests plus the relevant host/guest integration test before removing the marker. The test must cover the architectural boundary, unchanged behavior for existing inputs, and failure/overflow behavior where applicable.
