# TF-WI-0029: Model NLX regions accurately in SSA CFGs

## Scope

NLX begin instructions are currently represented as branches to NLX targets, which is insufficient for calls whose dynamic exits remain live. SSA conversion conservatively rejects functions with NLX; retain until dynamic-contour modeling is implemented and tested.

The missing edge is not expressible through the current `successors` generic:
call instructions have an ordinary fall-through continuation as well as
zero-or-more dynamic NLX targets, but the generic method has no enclosing
function/contour argument. Adding target edges directly to every call would
also make non-NLX calls appear to have impossible successors and would alter
dominance and phi placement.

### Minimal implementation design

1. Compute immutable dynamic contours once per backend function.
2. Build an SSA-specific successor relation that augments call instructions
   only when their contour contains a `begin-nlx-instruction`, retaining the
   normal continuation edge.
3. Feed that relation to dominance, liveness, and phi placement without
   changing the generic CFG `successors` protocol.
4. Add fixtures for calls with zero, one, and nested NLX targets, asserting
   equivalent fall-through SSA and rejection of unsafe cross-target phis.

## Required evidence

Add focused host, compiler/codegen, and (where applicable) cold-image tests
covering success, boundary, and failure behavior before removing the marker.
