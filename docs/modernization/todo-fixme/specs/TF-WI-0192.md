# TF-WI-0192: x86 fixnum shift bignum construction boundary

The x86-64 fixnum shift fast path checks sign extension and delegates overflow
to `%fixnum-left-shift-slow`. An inline bignum result must preserve register
layouts, no-frame GC metadata, count limits, and canonical representation.

Required evidence: x86-64 LAP/codegen tests and guest/host arithmetic tests for
positive, negative, and boundary counts before changing this path.
