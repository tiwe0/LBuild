# TF-WI-0021: Preserve debug variable locations across call canonicalization

## Scope

`canonicalize-call-operands` rewrites call results into physical return
registers. The baseline requirement is to emit matching debug-variable updates
when this rewrite changes the value location.

## Current boundary

The pass runs before debug-variable cleanup and currently has no executable
codegen/cold-image fixture proving that variable locations remain valid across
the inserted move. This item remains active until the allocator debug map and
call-result rewrite are covered together; the marker is intentionally retained.

## Required evidence

Add codegen, cold-image, and host tests covering register moves, optimized
debug information, and unchanged non-debug output before removing the marker.
