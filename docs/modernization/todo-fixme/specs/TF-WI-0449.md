# TF-WI-0449 — Cold serializer 宽字符字符串

- **基线标记：** `TF-occ-6ab44d5b1e8b7dca8973b4d4`
- **代码事实源：** `Lambda64/tools/cold-generator2/serialize.lisp:401`
- **风险：** high
- **要求测试层：** host、cold-image

## 目标与实现

字符串序列化根据所有字符的 code point 选择最窄可用存储：Latin-1 使用 8 位，
BMP 字符使用 16 位，其余 Unicode 字符使用 32 位；数据容量和小端打包步长随元素
宽度计算，并使用运行时已有的数组存储标签。

## 先测试证据

`Lambda64/tests/host/test-cold-serialize-wide-string.sh` 检查 16/32 位标签、按宽度
分配和字符编码，并确认删除 32 位分支的突变会被拒绝。
