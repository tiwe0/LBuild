# TF-WI-0008: Preserve ignored results for ARM64 predicate builtins

## Scope

The ARM64 builtin lowering path should optimize a predicate consumed by a
branch even when the builtin also returns values that the caller ignores.

## Current boundary

`lower-predicate-builtin` currently accepts only builtins whose result list
contains exactly one predicate. Compare-and-swap style builtins may return a
predicate together with prior values; relaxing this guard without allocating
virtual registers for those ignored values would pass an incomplete result
shape to the generator and could lose the atomic side effect.

## Required evidence

Add host, codegen, and cold-image tests covering predicate-only consumers,
ignored prior values, observed prior values, and side-effect preservation
before removing the marker. The ARM64 result ABI and branch lowering must stay
compatible with the x86-64 implementation boundary tracked by TF-WI-0031.
