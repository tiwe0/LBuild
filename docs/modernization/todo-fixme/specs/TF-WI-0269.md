# TF-WI-0269 — 串口字符写入原子性

- **基线标记：** `TF-occ-840c8c716bd4a36c442f66ec`
- **代码事实源：** `Lambda64/supervisor/serial.lisp:144-158`
- **风险：** critical
- **要求测试层：** host、cold-image、integration

## 目标

`debug-serial-write-char` 现在在关闭中断的同一临界区内持有一次
`*debug-serial-lock*`，并使用未加锁的 byte 原语完成整个 UTF-8 character。换行的
CRLF 两个 byte 因此不能被其他 writer 插入；普通字符保持原有的 UTF-8 输出和
`*serial-at-line-start*` 状态转换。

## 先测试证据

`Lambda64/tests/host/test-supervisor-serial-character-atomicity.sh` 在旧实现上失败：

```text
CRLF used 2 lock acquisitions instead of one
```

该回归模拟 byte writer 的锁边界，验证 CRLF 只获取一次锁、顺序输出 `0D 0A`，以及
普通 ASCII character 的单次锁获取和行首状态。mutation 负例把 CR 重新改为公共
locking byte writer，必须使测试失败。
