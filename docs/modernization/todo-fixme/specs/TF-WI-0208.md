# TF-WI-0208: AHCI cache flush commands

## Scope

This specification closes the corresponding AHCI driver marker in
`Lambda64/supervisor/ahci.lisp`.

## Required behavior

- Flush configures a zero-entry PRDT and issues FLUSH CACHE or FLUSH CACHE EXT according to drive addressing support.
- Failure paths do not publish successful I/O completion.

## Test-before evidence

The original implementation retained the baseline marker and lacked this
contract. `test-supervisor-ahci-contracts.sh` failed before implementation; the
behavior test additionally exercises extracted production address, transfer-limit,
bounce-buffer, and LBA encoding functions.

## Acceptance evidence

`Lambda64/tests/host/test-supervisor-ahci-contracts.sh` checks the production
command, recovery, and cleanup paths. `test-supervisor-ahci-behavior.sh` executes
the production pure/facade-compatible paths including boundary and negative cases.
Focused tests and Lisp style checks pass. Real QEMU AHCI and physical-controller
recovery evidence remains outstanding, so the work item stays active.
