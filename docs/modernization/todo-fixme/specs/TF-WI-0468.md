# TF-WI-0468: Route virtio MMIO interrupts by GIC specifier type

## Scope

Close the IRQ routing FIXME in `Lambda64/supervisor/virtio-mmio.lisp`.

## Contract

The FDT GIC interrupt specifier's first cell identifies the type (`0` SPI,
`1` PPI), and the second cell carries the interrupt ID. The registration path
now maps SPI IDs with base 32 and PPI IDs with base 16 into the global IRQ
namespace. Unsupported types are rejected before device registration rather
than being silently misrouted.

## Verification

`Lambda64/tests/host/test-supervisor-virtio-mmio-irq-routing.sh` checks the
specifier decoding, both base conversions, and unsupported-type rejection
contract.
