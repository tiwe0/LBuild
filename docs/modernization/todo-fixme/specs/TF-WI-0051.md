# TF-WI-0051 — 交叉编译 complex short-float 提升语义

- **基线标记：** `TF-occ-c072b2e35a183a57f5ee89ff`
- **代码事实源：** `Lambda64/compiler/cross.lisp:165-173`、`Lambda64/compiler/cross-compile.lisp:724-740`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 当前边界

交叉编译器将目标 `complex` 类绑定到宿主 `cl:complex`，同时以 `cross-complex-short-float` 保存目标的半精度复数常量。`mezzano.compiler:complex` 仅在任一分量为 `cross-short-float` 时构造该表示，并断言另一分量也已转换；TODO 所指的“按需提升”语义尚未定义。当前行为对混合分量（例如目标 short-float 与宿主整数/浮点）的处理是断言失败，不能在无目标数值格式和舍入规则证据时直接修改。

## 当前证据

`cross-file-compiler.lisp` 与 `cold-generator2/serialize.lisp` 已针对 `cross-complex-short-float` 实现 16-bit 分量序列化；`system/type.lisp`/`runtime-array.lisp` 定义了目标 `(complex short-float)` 布局。尚无覆盖混合分量、溢出/舍入及 NaN 的端到端 codegen/cold-image 测试，因此 marker 保持 active。

## 后续验收

1. 明确 short-float 分量的提升、舍入、溢出及特殊值策略，并与目标运行时 `(complex short-float)` 表示一致。
2. 对两个已转换分量保持现有序列化字节；混合分量按规范转换或明确拒绝，不能依赖宿主 `assert`。
3. 增加 host、codegen、cold-image focused tests（含混合分量和边界值）后，才可移除 marker。
