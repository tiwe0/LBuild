# TF-WI-0122 — USB 端口连接事件错误处理

- **基线标记：** `TF-occ-e83d25d79ba167b3b99312fd`
- **代码事实源：** `Lambda64/drivers/usb/usb-driver.lisp:232-292`
- **风险：** high
- **要求测试层：** host、hardware

## 目标

端口连接枚举流程捕获控制器断开和其他条件，输出带事件上下文的诊断，而不是让
工作线程静默吞掉异常；既有设备互斥锁清理和 `:probe-failed` 语义保持不变。

## 先测试证据

新增 `Lambda64/tests/host/test-driver-usb-event-error-handling.sh`，检查 `handler-case`
包含 `controller-disconnect` 与通用 `error` 分支及 port-connect 诊断。实现前测试因
TODO 而失败，变异负例移除错误分支会被拒绝。

## 验收标准

1. 控制器断开和一般错误均记录明确原因。
2. 错误处理后不跨越未释放的设备锁。
3. 在 `hardware-usb-usb-driver` 资源可用时完成真实插拔回归；当前工作项保持 `active`。
