# TF-WI-0479: Define PCI driver redefinition lifecycle boundary

## Scope

Close the detach/reprobe TODO in `Lambda64/supervisor/pci.lisp`.

## Contract

`pci-driver` currently provides only a probe callback; claimed PCI devices do
not expose a detach or transport-reset lifecycle hook. Incompatible driver
redefinitions therefore remain rejected rather than clearing ownership and
probing live devices again. A future reprobe implementation must first add an
explicit teardown contract that safely quiesces device state.

## Verification

`Lambda64/tests/host/test-supervisor-pci-driver-reprobe-boundary.sh` checks
that the TODO is closed and that incompatible redefinition remains a guarded,
non-destructive boundary.
