# TF-WI-0234: ATA PIO input logical-sector contract

## Scope

This contract resolves the baseline directive in
`Lambda64/supervisor/ata.lisp` while preserving the legacy PCI ATA/ATAPI
interface and its existing successful command paths.

## Required behavior

IDENTIFY words 117 and 118 encode a count of 16-bit words. When word 106 marks
the field valid with bits 15:14 equal to `01` and bit 12 indicates a logical
sector longer than 256 words, the driver multiplies that count by two before
storing `ata-device-block-size`; otherwise it uses 512 bytes. PIO input
transfers exactly `ata-device-block-size / 2` words per sector. Logical sector
size must be positive and even because the legacy data port is 16 bits wide;
unsupported odd sizes fail before I/O.

Controller recovery aborts bus mastering, clears stale bus-master interrupt and
error state, clears the IRQ latch and selected-device cache, asserts SRST with
interrupts masked for 5 microseconds, deasserts it, waits for BSY to clear, and
then re-enables device interrupts. Recovery returning false means reset itself
did not complete before its deadline; the original command remains failed.

## Test-before evidence

Before implementation,
`bash Lambda64/tests/host/test-supervisor-ata-recovery-and-transfer.sh` exited
with status 1 at the first missing form, `ata-timeout-deadline`. The source still
contained the matching directive and did not expose the recovery, exact-copy,
or transfer-size primitives required by the fixture.

## Acceptance evidence

The fixture covers all invalid word-106 encodings independently: bit 12 clear, bit 14 clear, and bit 15 set each fall back to 512 bytes. Its error assertion is outside the handler, so removing the positive/even guard cannot false-green; targeted mutations removing that guard or the bit-15 validity check both make the focused test fail.

The behavior fixture feeds the production IDENTIFY decoder words 117/118 =
2048 and proves it yields a 4096-byte block followed by a 2048-word PIO sector.
It also proves an odd 513-byte sector is rejected.

`Lambda64/tests/host/test-supervisor-ata-recovery-and-transfer.sh` also executes
the real reset sequence, exact byte copy, bounce branch, logical-sector
validation, and LBA28/LBA48 command helpers against deterministic host I/O
facades. Lisp style, documentation, marker, and whitespace checks cover the
host-local contract.

The expanded production-direct fixture loads and executes the real IRQ wait,
Check_Status, PIO input/output, PRDT construction, DMA completion, flush, and
PACKET control-flow functions. Only hardware primitives such as port access,
timer wakeup, and memory access are simulated.

The ledger also requires cold-image and integration evidence. No current run
has exercised these paths against QEMU/Bochs or physical ATA/ATAPI hardware, so
this work item remains active and does not claim hardware verification.
