# TF-WI-0258: Define first-boot runtime global initialization boundary

## Scope

Close the cold-generator initialization FIXME in
`Lambda64/supervisor/entry.lisp`.

## Contract

On the first supervisor boot, `entry.lisp` resets active catch handlers,
pseudo-atomic state, known finalizers, and the object-wait lock after allocator
initialization. The current cold generator does not emit initialized values for
these globals, so this bootstrap reset remains required. Moving it to generated
images requires an explicit generated-image ABI extension and corresponding
regression coverage.

## Verification

`Lambda64/tests/host/test-supervisor-entry-cold-init-boundary.sh` checks marker
removal and retention of the first-boot global reset contract.
