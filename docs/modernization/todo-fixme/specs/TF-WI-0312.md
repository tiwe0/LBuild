# TF-WI-0312 — LOOP typed initializer 的宏环境

- **基线标记：** `TF-occ-6575f01cf16ba4dfad9e255f`
- **代码事实源：** `Lambda64/system/ansi-loop.lisp:1091-1104`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`loop-typed-init` 在展开 LOOP 类型声明时必须把当前
`*loop-macro-environment*` 传给 `sys.int::typeexpand`。这样局部 `deftype` 或类型宏
定义才能影响初始化值推导，同时保留直接调用时的既有默认行为。

## 先测试证据

新增 `Lambda64/tests/host/test-system-ansi-loop-typeexpand-environment.sh`，检查函数
签名暴露可选环境参数、`typeexpand` 使用该参数，并确认移除环境参数的变异会被拒绝。

## 验收标准

1. LOOP 翻译期间使用动态绑定的宏环境进行类型展开。
2. 未显式传入环境时保持原有调用点行为，不改变初始化值规则。
3. 现有浮点、数字和向量初始化分支保持不变。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
