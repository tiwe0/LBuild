# TF-WI-0421 — `ROTATEF` 的 generalized-place 语义

- **基线标记：** `TF-occ-16e935ab0cb4bfb44adcf96f`
- **代码事实源：** `Lambda64/system/setf.lisp:201-243`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`ROTATEF` 直接使用每个 place 的 `get-setf-expansion`：先按源顺序只求值一次所有 place
subform，再读取所有旧值，最后写回循环后的 store values。它不再把 place 作为另一个
`PSETF` value form 重复出现。实现保留零 place 返回 `nil`，并支持有多个 store variable
的 generalized place；缺少的轮转值遵循 Common Lisp 多值绑定的 `nil` 规则。

## 先测试证据

`Lambda64/tests/host/test-system-rotatef-semantics.sh` 对基线版本失败：

```text
ROTATEF evaluated place subforms 4 times
```

回归覆盖三位置循环、带副作用的 `car` place 各求值一次、零位置返回值，以及双 store
variable generalized place 的并行轮转。mutation 负例破坏尾部到首位置的连接，确保循环
写回次序受到测试保护。
