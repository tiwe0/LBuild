# TF-WI-0421: Structure definition layout hash initialization

## Change

Structure-definition layouts now initialize `layout-hash` with `(sxhash name)`
before the CLOS class receives its generated hash. The name hash provides a
stable probing key during bootstrap; fast class-hash tables still compare class
identity, so collisions remain safe.
