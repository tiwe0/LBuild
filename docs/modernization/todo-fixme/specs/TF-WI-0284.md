# TF-WI-0284: wired push place evaluation boundary

`push-wired` now obtains the standard SETF expansion for `PLACE`, evaluates
place subforms once, and allocates the replacement cons in the wired area.
The expansion preserves the caller's place protocol while avoiding duplicate
reads or side effects from complex places.
