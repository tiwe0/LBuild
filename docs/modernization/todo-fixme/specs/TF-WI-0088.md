# TF-WI-0088 — RTL8168 DMA 缓冲区分配校验

- **基线标记：** `TF-occ-41f921f59e6fa8b104814e13`
- **代码事实源：** `Lambda64/drivers/rtl8168.lisp:234-275`
- **风险：** high
- **要求测试层：** host、hardware

## 目标

RTL8168 复位前显式确认 TX/RX 描述符环和 bounce buffer 的物理、虚拟地址均已分配；
任一分配失败立即报错，避免向空地址写入 DMA 描述符。

## 先测试证据

新增 `Lambda64/tests/host/test-driver-rtl8168-buffer-allocation.sh`，检查复位路径覆盖
八个 DMA 地址并在失败时抛出诊断；变异负例移除 `unless` 守卫，必须被测试拒绝。实现前
测试因 FIXME 而失败。

## 验收标准

1. 八个 TX/RX ring/bounce 地址全部校验。
2. 校验失败不会继续写 NIC 描述符。
3. 在 `hardware-rtl8168` 资源可用时完成真实初始化回归；当前工作项保持 `active`。
