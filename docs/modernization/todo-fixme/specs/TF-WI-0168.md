# TF-WI-0168: TCP bounded send and buffering contract

## Required behavior

Application bytes are copied into connection-owned MSS-sized pending segments.
Transmission is limited to `min(SND.WND, CWND) - flight-size`; partial segments
remain buffered, zero-window sends transmit nothing, and later ACK/window
updates flush newly available capacity. The final PSH indication survives
partial flushing. Abort publication freezes every send path and clears both
pending application data and retransmission queues.

## Evidence

The focused test extracts production queue/flush/send functions and drives the
full receive ACK path. Its deferred FIFO scenario places a window-reopening ACK
ahead of abort, then proves the ACK emits no queued data after synchronous abort
publication. Direct MSS tests prove source-copy ownership, partial retention,
zero-window suppression, and reopen flushing; a no-op queue mutant is rejected.
The inverse limit case proves `CWND < SND.WND` is congestion-window bounded,
and the final remainder receives PSH only when a reopened window transmits its
last bytes. Ignoring CWND or stripping PSH are rejected mutants. Real peer
backpressure and persist probes remain a guest/network gap.
