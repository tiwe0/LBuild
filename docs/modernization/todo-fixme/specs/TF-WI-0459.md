# TF-WI-0459: Document virtio transitional PCI transport boundary

## Scope

Close the two feature TODOs in `Lambda64/supervisor/virtio-pci.lisp` without
claiming unsupported modern-mode behavior.

## Contract

Transitional devices are currently registered through the legacy BAR-0
transport. Virtio 1.x requires negotiating `VIRTIO_F_VERSION_1` before using
the modern PCI capability layout; probing that bit without a complete reset,
feature-negotiation, and transport switch would leave device state ambiguous.
The implementation therefore documents the boundary and preserves the existing
legacy path until that larger protocol change is implemented.

## Verification

`Lambda64/tests/host/test-virtio-pci-transitional-contract.sh` verifies removal
of both stale markers and preservation of the explicit VERSION_1/legacy-boundary
contract.
