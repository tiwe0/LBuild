# TF-WI-0015: ARM64 single-float boxing without temporary register

The ARM64 `box-single-float` emitter uses the instruction destination GPR as
its scratch register. GPR sources are shifted directly; FP-32 sources move
through the destination W view before shifting. Immediate tag composition is
unchanged and no fixed scratch register is clobbered.

`Lambda64/tests/host/test-system-disassemble-arm64-box-single-float.sh` checks
both source register classes and rejects a mutation restoring `:x9`. Full
codegen/cold-image execution is not recorded by this focused source test.
