# TF-WI-0263: Define stack guard zero-fill transition boundary

The guard return fault path intentionally discards the protected soft-guard
pages and recreates them zero-filled on the next access. This is coupled to the
pager's page-release behavior and must not be replaced by a protection-only
operation until page retention semantics are implemented and tested.

Verification: `Lambda64/tests/host/test-supervisor-pager-boundaries.sh`.

# TF-WI-0263: Define pager unhandled-fault panic boundary

## Scope

Close the unhandled-fault panic TODO in `Lambda64/supervisor/pager.lisp`.

## Contract

Unhandled paging faults continue through the pager panic path until a debugger
thread handoff protocol exists. Such a handoff must transfer the saved frame,
VM lock ownership, and panic policy atomically; dispatching without that
contract could strand the faulting thread or deadlock the pager.

## Verification

`Lambda64/tests/host/test-supervisor-pager-panic-contract.sh` checks marker
removal and preservation of the panic-path safety contract.
