# TF-WI-0373 — invalid argument backtrace frames

- **基线标记：** `TF-occ-7d8545fe347000b82e373835`
- **代码事实源：** `Lambda64/system/error.lisp:418-424`、x86 argument-check emitters
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

参数数量检查失败时，调用 `RAISE-INVALID-ARGUMENT-ERROR` 必须保留被调用函数的
栈帧，使调试器 backtrace 显示实际出错函数。x86 路径改为普通 call 并经自身
epilogue 返回；不再依赖 `FUNCTION-FROM-FRAME` 的替换 hack。错误类型、参数和
`specify-arguments` restart 语义保持不变。

## 先测试证据

`Lambda64/tests/host/test-system-invalid-argument-backtrace.sh` 检查编译器和运行时
x86 路径均使用 call/return，且 debugger hack 与 FIXME 已移除；变异回归确认重新
引入 tail-jump 会失败。

## 验收标准

1. x86 编译器与运行时 argument-check 路径保留 caller frame。
2. backtrace 不再需要特殊替换逻辑。
3. invalid-argument-error/restart 的既有可观察语义不变。
4. host、cold-image、integration 验证待完整构建环境恢复后执行，工作项保持 active。
