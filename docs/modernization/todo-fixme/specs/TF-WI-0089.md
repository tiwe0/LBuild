# TF-WI-0089: Bound RTL8168 diagnostic register dump

## Scope

Close the `Get the remaining registers` marker in
`Lambda64/drivers/rtl8168.lisp`. The `dump` helper intentionally reports only
stable identity and multicast registers.

## Safety contract

The remaining RTL8168 register window includes write-one-to-clear status,
command, and active DMA pointer fields. Reading those registers generically can
acknowledge events or race I/O, so this change documents the bounded diagnostic
surface rather than issuing speculative reads. Additional fields require
register-specific decoders and side-effect review.

## Verification

`Lambda64/tests/host/test-rtl8168-dump-contract.sh` checks marker removal,
the safety rationale, and preservation of the existing 14-byte dump surface.
