- **要求测试层：** codegen、cold-image、host

`MOVSS` and `MOVSD` support both directions: register destination from
memory/register source (`0F 10`) and memory destination from an XMM register
source (`0F 11`). Existing load encoding remains unchanged; packed forms remain
governed by their existing definitions.
