# TF-WI-0430: Allocation profiler raw format contract

## Change

Allocation profiling intentionally returns nested triple vectors of
`(function, bytes, children)`, consumed by `generate-allocation-flame-graph`.
Normal sampling uses `profile-data` and cannot share the representation without
changing public decoding and save semantics.
