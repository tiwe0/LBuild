# TF-WI-0248: Define CD-ROM single-track disk contract

The SCSI CD-ROM driver registers the medium as one contiguous 2048-byte block
device. Multi-session or mixed-mode media needs partition/session discovery in
the disk layer; interpreting additional tracks here would violate that layer
boundary. Keep the single-data-track assumption explicit until that support is
implemented and covered by hardware/integration tests.

Verification: `Lambda64/tests/host/test-supervisor-pager-boundaries.sh`.
