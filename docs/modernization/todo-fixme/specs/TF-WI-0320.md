# TF-WI-0320 — 原子 RMW 优先使用直接操作

- **基线标记：** `TF-occ-c3c1619242447528243a19a7`
- **代码事实源：** `Lambda64/system/cas.lisp:114-190`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`define-atomic-rmw-operation` 为支持的 place 生成 operation-specific 原子调用：全局
符号使用 `symbol-function`，结构槽使用 `struct-slot-function`，CAR/CDR 使用对应的
cons operation；只有无法识别的 place 才回退到 CAS loop。这样避免在已有硬件原子原语
可用时重复执行软件 CAS 循环。

## 验收标准

1. 支持的全局符号、结构槽和 cons place 走 operation-specific 原子调用。
2. 未识别 place 保留 CAS loop，结果和返回值语义不变。
3. 不新增额外依赖或改变既有 `atomic-*f` 公共接口。
4. cold image 与 QEMU integration 待完整环境验收，工作项保持 `active`。
