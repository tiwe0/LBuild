# TF-WI-0465: Isolate GC finalizer errors

## Scope

`run-finalizers` catches errors from each callback, reports them through the
supervisor console without allowing reporter failures to abort the queue, and
always clears the callback reference in `unwind-protect`.

## Verification

`Lambda64/tests/host/test-system-gc-finalizer-errors.sh` checks the handler,
reporting guard, cleanup, and mutation negatives. Full GC-worker and cold-image
validation remains required before this work item can be considered complete.
