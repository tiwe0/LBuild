# TF-WI-0465: Define ARM64 early console configuration boundary

## Scope

Close the hardcoded IRQ, baud, reinitialization, and FDT cell-count markers in
`Lambda64/supervisor/arm64/platform.lisp`.

## Contract

The early DW-APB UART console is polled (IRQ 0), uses the existing 115200 baud
default because `stdout-path` baud-option parsing is not implemented, and does
not reinitialize during early boot. The current QEMU root-level FDT provides one
address/size cell for DW-APB UART and two for PL011; these values remain scoped
to that platform shape. Generalized cell inheritance and baud parsing require a
boot-configuration API before they can be enabled safely.

## Verification

`Lambda64/tests/host/test-supervisor-arm64-platform-console-contract.sh` checks
marker removal and preservation of the explicit early-console assumptions.
