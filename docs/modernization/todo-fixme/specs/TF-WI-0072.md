# TF-WI-0072: Multiple-value GC metadata adjustment invariant

## Scope

This specification defines the live-count adjustment encoded by
`:multiple-values` GC metadata in `Lambda64/doc/internals/abi.md`.

## Required documentation contract

The collector derives the live multiple-value count from the saved `RCX` fixnum
plus the metadata adjustment. Values beyond the five return registers occupy
consecutive slots beginning at the current thread's multiple-value save-area
base. The adjustment affects only the live count, not that layout.

Current metadata producers use only `nil`, `0`, and `1`. Zero means `RCX` is
current. One covers the instruction window after an extra save-area slot has
been written and before `RCX` is incremented. The field remains four bits wide;
15 encodes `nil`, and the decoder can represent 0 through 14 for the existing
format. Adjustments 2 through 14 are encoding capacity, not valid states emitted
by the current x86-64 or arm64 compiler/LAP sources.

## Test-before evidence

Before the documentation change, the guide exposed the full encoded range and
left a marker saying the flexibility was unnecessary. It did not identify the
two producer states or explain why adjustment one is needed.

## Acceptance evidence

The following focused check proves that repository producers currently emit no
adjustment other than zero or one:

```sh
python3 - <<'PY'
import pathlib, re
roots = [pathlib.Path('Lambda64/compiler'), pathlib.Path('Lambda64/runtime'),
         pathlib.Path('Lambda64/system'), pathlib.Path('Lambda64/supervisor')]
values = set()
for root in roots:
    for path in root.rglob('*.lisp'):
        values.update(map(int, re.findall(r':multiple-values\s+([0-9]+)',
                                          path.read_text())))
assert values <= {0, 1}, values
assert values == {0, 1}, values
PY
```

The encoder and collector anchors are checked separately:

```sh
rg -n 'gcmd-flag1-multiple-values|or multiple-values #b1111' Lambda64/compiler/lap.lisp Lambda64/system/data-types.lisp
rg -n 'n-values \(\+ .*multiple-values\)|n-mv-area-values' Lambda64/system/gc.lisp
```

`make docs-check` and `git diff --check` complete the static validation. This
work item documents the existing ABI and does not change the binary metadata
format.
