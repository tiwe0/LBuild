# TF-WI-0327: Class layout obsolescence protocol

## Scope

This work item closes the corresponding CLOS runtime marker in
`Lambda64/system/clos/closette.lisp`.

## Required behavior

- Finalization computes a candidate layout and invokes MAKE-INSTANCES-OBSOLETE for incompatible prior layouts; that operation rebuilds and installs the current layout.
- Existing bootstrap-safe paths and standard generic-function fast paths remain available.

## Test-before evidence

The old finalizer directly mutated layout links. The focused source-contract test failed against that implementation.

## Acceptance evidence

`Lambda64/tests/host/test-system-closette-modernization.sh` checks the production
forms for this contract, while `test-system-closette-behavior.sh` executes the
pure layout, method-list, environment, and EQL-cache paths and the complete removal of TODO/FIXME markers from the
file. The focused test and Lisp style checks pass. A cold-image build and guest
CLOS redefinition/dispatch exercise remain outstanding, so this item stays active.
