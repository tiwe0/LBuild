# TF-WI-0198 — SIMD 整数元素类型统一解析

- **基线标记：** `TF-occ-e2cb89d4c9fcf9134c707861`
- **代码事实源：** `Lambda64/runtime/simd.lisp:40-105`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 目标

将 SIMD 整数元素类型解析集中到 `resolve-simd-integer-element-type`：保留既有
`SUBTYPEP` 等价类型的固定宽度兼容性，同时统一处理任意正的 2 次幂宽度。`pow2p`
拒绝零宽度，避免计算出负的 header 宽度。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-simd-element-type-resolution.sh`，检查统一解析
函数、正宽度约束和 header 写入；变异负例将正宽度检查改为零宽度检查，必须被拒绝。
实现前测试因缺少统一解析契约而失败。

## 验收标准

1. unsigned/signed 整数元素类型共享一套 kind/width 解析逻辑。
2. 固定宽度等价类型 `(unsigned-byte|signed-byte 8/16/32/64)` 保持原有结果。
3. 零或非 2 次幂宽度被拒绝，不生成非法 header。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
