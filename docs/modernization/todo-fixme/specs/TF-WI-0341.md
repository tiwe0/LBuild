# TF-WI-0341 — Fast class hash 单项弱指针读取

- **基线标记：** `TF-occ-30c6494eaa85eb9b84038205`
- **代码事实源：** `Lambda64/system/clos/fast-class-hash-table.lisp:32`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标与实现

单项 fast class hash table 查找现在使用公开的 `weak-pointer-pair`，一次读取 key、
value 和 live 标志；死亡弱指针不会被误认为命中。此路径不再依赖仅供优化阶段使用的
内部 `%weak-pointer-key/value` 访问器。

## 先测试证据

`Lambda64/tests/host/test-system-fast-class-hash-pair.sh` 检查 pair API、live 校验和
class 匹配逻辑，并确认替换 pair 读取的突变会被拒绝。
