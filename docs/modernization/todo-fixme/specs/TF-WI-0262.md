# TF-WI-0262: Define stack guard reprotection page preservation boundary

Reprotecting the soft stack guard currently uses `+block-map-zero-fill+`,
which deliberately releases old pages. Removing that flag requires extending
`protect-memory-range-in-pager` with a way to clear presence while retaining
page contents. Until that VM contract exists, preserve the explicit behavior
and keep this item active rather than silently changing stack semantics.

Verification: `Lambda64/tests/host/test-supervisor-pager-boundaries.sh`.
