# TF-WI-0163: TCP passive-open timeout contract

## Required behavior

Every inbound connection in `:SYN-RECEIVED` arms the bounded
`*TCP-SYN-RECEIVED-TIMEOUT*`. Duplicate handshake traffic may restart that
timer. Expiry records `CONNECTION-TIMED-OUT`, removes the listener reservation,
releases backlog capacity, detaches the connection, and wakes waiters.

## Evidence

The focused host regression extracts and executes production
`TCP4-OPEN-PASSIVE`, `UPDATE-TIMEOUT-TIMER`, `TIMEOUT-TIMER-HANDLER`, and
`RETRANSMIT-TIMER-HANDLER`. It verifies initial SYN+ACK timer arming, bounded
half-open timeout cleanup (pending hash, backlog, condition, and detach),
retransmission, and RTO backoff. A syntax-valid no-op timeout-handler mutant is
rejected. Packet loss and real timer scheduling remain guest/network validation.
