# TF-WI-0028: Enforce 16-byte stack alignment for SIMD spills

## Scope

Spill-slot assignment pads SIMD values but does not guarantee a 16-byte aligned base under every preceding spill arrangement. Retain until frame-layout alignment and generated-code tests cover SSE/AdvSIMD combinations.

## Required evidence

Add focused host, compiler/codegen, and (where applicable) cold-image tests
covering success, boundary, and failure behavior before removing the marker.
