# TF-WI-0362 — DESCRIBE 的 proper/dotted/circular list 识别

- **基线标记：** `TF-occ-20679c66cf07e47e8b846252`
- **代码事实源：** `Lambda64/system/describe.lisp:173`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`describe-object` 的 cons 专用方法必须区分 proper list、dotted list 与 circular list，
而不是将所有 cons 统一描述为 `list`。环检测必须先于末尾检查，避免在 circular list
上进行无终止遍历。

## 先测试证据

新增 `Lambda64/tests/host/test-system-describe-list-kind.sh`。测试从生产源提取 cons 的
`describe-object` 方法，使用 proper、dotted 与 self-circular cons 并开启循环打印保护。

实现前运行：

```sh
bash Lambda64/tests/host/test-system-describe-list-kind.sh
```

失败并输出 `(A B) is a list`，证明旧实现没有揭示列表形态。

## 验收标准

1. proper、dotted、circular list 的描述分别包含相应形态名称。
2. circular list 先经 `dotted-list-length` 判定；只有非循环列表才检查最后 cons 的 cdr。
3. 描述仍保留对象打印及地址信息。
4. host 测试直接加载生产方法，并以破坏环检测调用的变异负例锁定分派；cold image 与
   QEMU integration 在后续完整测试阶段补齐。
