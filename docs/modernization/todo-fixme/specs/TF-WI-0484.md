# TF-WI-0484: Define x86 interrupt initialization boundaries

## Scope

Close the interrupt initialization markers in
`Lambda64/supervisor/x86-64/interrupts.lisp` without approximating hardware
routing or changing boot allocation semantics.

## Contract

The current x86 supervisor path initializes and masks the legacy dual 8259 PIC.
APIC/IO-APIC support requires a separate topology and interrupt-routing
contract, so no partial setup is attempted here. Wired interrupt vectors are
allocated lazily once and reset on every boot; moving allocation into cold
image generation is deferred until a serializer contract exists.

## Verification

`Lambda64/tests/host/test-supervisor-x86-interrupt-boundaries.sh` checks marker
removal and preserves both hardware-routing and allocation contracts.
