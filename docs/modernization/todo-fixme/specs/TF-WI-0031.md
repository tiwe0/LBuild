# TF-WI-0031: Preserve ignored results for predicate builtins

## Scope

The x86-64 builtin lowering path should optimize a predicate consumed by a
branch even when the builtin also returns values that the caller ignores.

## Current boundary

The current guard only accepts a single builtin result. Compare-and-swap
builtins return a predicate plus prior values, so simply relaxing the guard
would call generators with the wrong number of result virtual registers. A
correct implementation must materialize temporary vregs for ignored outputs,
preserve the cmpxchg side effect, and prove codegen compatibility.

## Required evidence

Add host, codegen, and cold-image tests covering predicate-only consumers,
observed prior values, and side-effect preservation before removing the marker.
