# TF-WI-0310 — LOOP numeric accumulator declaration compatibility

- **基线标记：** `TF-occ-cd06a86694b519d42cfe3371`
- **代码事实源：** `Lambda64/system/ansi-loop.lisp:150`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 决策

`*loop-real-data-type*` 保持为 `T`，而不是恢复为 `REAL`。LOOP 将该类型用于
编译器生成的 MAX/MIN 绑定；Lambda64 编译器把声明作为优化假设，并可能以 `THE`
包裹初始化表达式。对未知或用户定义的 MAX/MIN 表达式收紧为 `REAL` 会改变代码生成
和安全检查路径，不能证明语义与性能等价，因此不作收紧。

源文件中的说明注释已取代 FIXME，明确记录这一兼容性边界。聚焦 host 合约测试同时
锁定 `T` 声明并以变异方式确认收紧为 `REAL` 会失败。
