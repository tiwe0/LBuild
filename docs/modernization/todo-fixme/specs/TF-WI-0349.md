# TF-WI-0349 — 结构父类变更维护

- **基线标记：** `TF-occ-4b133e43da79ac2e5a763110`
- **代码事实源：** `Lambda64/system/clos/struct.lisp:125`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标与实现

重新定义结构类型时解析新父类，并在父类发生变化时先从旧父类移除 direct
subclass，再向新父类添加。随后由结构布局填充逻辑更新类的其余元数据；父类未变时
不产生重复链接。

解析及 add/remove 调用，并确认删除旧父类移除步骤的突变会被拒绝。
