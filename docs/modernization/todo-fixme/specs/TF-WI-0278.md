# TF-WI-0278: Sparse card-table backing initialization contract

## Scope

This item covers initial allocation of backing frames for the sparse card-table
range.

## Required behavior

`ALLOCATE-SNAPSHOT-WIRED-BACKING-PAGES` receives `:SPARSE T` for the card table.
It iterates only populated page-table branches, collects present mappings per
2 MiB chunk, and allocates no backing frame for absent regions.

## Test-before evidence

The focused test reported the boot-time sparse-scan marker. The old code relied
on a sparse option locally but did not share or document the per-chunk backing
contract.

## Acceptance evidence

The host contract extracts and executes production
`MAP-SNAPSHOT-WIRED-PAGES`, `SNAPSHOT-COPY-WIRED-AREA`, and
`ALLOCATE-SNAPSHOT-WIRED-BACKING-PAGES`. It observes `:SPARSE T` on card-table
mapping and verifies the chunk allocator's dense and partial/failure fallback
boundaries. Boot-time scan duration and actual card-table coverage remain guest
measurements.
