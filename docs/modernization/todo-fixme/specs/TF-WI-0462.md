# TF-WI-0462: Define disk request bounce-buffer lifetime boundary

## Scope

Close the bounce-buffer TODO in `Lambda64/supervisor/disk.lisp` without handing
movable Lisp arrays to asynchronous disk drivers.

## Contract

Object-backed byte arrays are copied through a wired physical bounce buffer,
which remains allocated until the driver callback completes. Removing this
copy requires a pinned-buffer API and an explicit DMA lifetime contract; neither
exists in the current supervisor API, so speculative direct mapping is unsafe.

## Verification

`Lambda64/tests/host/test-supervisor-disk-bounce-contract.sh` checks marker
removal and preservation of the wired-buffer/lifetime safety rationale.
