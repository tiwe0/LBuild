# TF-WI-0005: ARM64 AdvSIMD boxed type contract

## Scope

`box-advsimd-instruction` is a lane-specific instruction subtype, but its
header carries the lane details and the generic IR type query does not. The
query therefore intentionally returns the shared `mezzano.simd:simd-pack`
class used by SIMD builtins.

## Required behavior

- `ir:box-type` for `box-advsimd-instruction` returns exactly
  `mezzano.simd:simd-pack`.
- The method remains independent of the concrete lane/header subtype.
- No code-generation or runtime representation changes are implied.

## Acceptance evidence

`Lambda64/tests/host/test-compiler-arm64-box-type.sh` checks the method body
and rejects a mutation replacing the shared SIMD pack type with `nil`.
Guest/codegen and cold-image evidence remain required by the work-item ledger.
