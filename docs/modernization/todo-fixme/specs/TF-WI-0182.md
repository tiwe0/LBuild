# TF-WI-0182: Direct funcallable-instance entry mutation contract

## Scope

Resolve the baseline directive at `Lambda64/runtime/function.lisp:299` while
preserving the `funcallable-instance-function` API and object layout.

## Required behavior

The setter publishes a raw entry point consistent with the new boxed target:
compiled function objects use their own entry directly; closures and nested
funcallable instances use `*funcallable-instance-trampoline*`. The boxed target
remains stored in slot `+funcallable-instance-function+` for GC and trampoline
loads. Type checks and existing access behavior are unchanged.

## Acceptance evidence

`bash Lambda64/tests/host/test-runtime-function-contracts.sh` checks both tag
routes, publication ordering, and rejects a mutation that replaces the direct
entry calculation with the trampoline. The test is host/static evidence only;
cold-image, concurrent SMP mutation, and integration call/GC behavior remain
required before marking this item verified.
