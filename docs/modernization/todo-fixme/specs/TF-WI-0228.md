# TF-WI-0228: Define ARM64 timer IRQ and cache-line configuration boundaries

## Scope

Close the PPI/SPI and cache-line configuration markers in
`Lambda64/supervisor/arm64/time.lisp` and `arm64/cache.lisp`.

## Contract

The architected virtual timer interrupt is a PPI and is translated by adding
GIC's PPI base (16) to its FDT interrupt ID. Device-specific SPI routing remains
with each FDT consumer. Cache maintenance uses the architectural conservative
64-byte line size until cache-type register decoding is available; I-cache
ranges align down/up to complete lines before issuing maintenance instructions.

## Verification

`Lambda64/tests/host/test-supervisor-arm64-time-cache-contract.sh` checks marker
removal, timer PPI rationale, conservative cache-size contract, and aligned
I-cache iteration.
