# TF-WI-0037: Define x86 STI/HLT scheduling boundary

## Scope

Close the scheduling guarantee marker in
`Lambda64/compiler/backend/x86-64/misc.lisp` for `sys.int::%stihlt`.

## Contract

The builtin emits `STI` immediately followed by `HLT`. The pair must remain an
indivisible sequence during lowering and scheduling because `STI` defers
interrupt delivery until the next instruction completes. This item records the
contract; a future scheduler change must preserve adjacency or add an
explicit backend bundle primitive.

## Verification

`Lambda64/tests/host/test-compiler-x86-stihlt-boundary.sh` checks marker removal
and the explicit adjacency contract.
