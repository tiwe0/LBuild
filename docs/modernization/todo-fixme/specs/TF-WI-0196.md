# TF-WI-0196 — SIMD `AREF` 的末 lane 边界检查

- **基线标记：** `TF-occ-ddb187724a1f77bd8a64208b`
- **代码事实源：** `Lambda64/runtime/simd-arm64.lisp:300-314`
- **风险：** high
- **要求测试层：** host、codegen、cold-image

## 目标

SIMD `AREF` 一次读取 `N` 个 lane，必须通过已检查的 row-major wrapper 验证最后一个
subscript 不会使读取范围越过数组末尾。底层 `%row-major-aref` 仅保留给已完成边界
验证的内部路径。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-simd-aref-bounds.sh`，检查生产宏生成的 `AREF`
wrapper 调用 checked `row-major-aref`，并验证 `index + N <= array-total-size` 断言；
变异负例改回 unchecked `%row-major-aref`，必须被测试拒绝。

实现前源码直接调用 `%row-major-aref`，且 TODO 明确指出最后 subscript 未检查；测试
会拒绝该状态。

## 验收标准

1. 向量读取越界在 wrapper 层被拒绝，不访问数组外存储。
2. 合法读取及既有 lane 组合保持不变。
3. 非 simple array 支持仍由现有标量/通用路径负责，不扩大本宏的类型承诺。
4. codegen、cold image 验证待 Quicklisp 与完整构建环境恢复后执行，工作项保持
   `active`。
