# TF-WI-0306: lazy interrupt-vector allocation

## Scope

`Lambda64/supervisor/x86-64/interrupts.lisp` modernization boundary.

## Contract

The IRQ/vector table is allocated lazily once and reset on each boot; moving allocation into cold generation remains deferred until serializer support exists.

## Verification

`Lambda64/tests/host/test-supervisor-x86-interrupt-boundaries.sh` checks the corresponding source anchors and rejects marker reintroduction.
