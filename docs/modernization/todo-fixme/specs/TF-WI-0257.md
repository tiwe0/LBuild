# TF-WI-0257: Synchronize disks and snapshots before reboot

## Scope

Close the reboot synchronization FIXME in `Lambda64/supervisor/entry.lisp`.

## Contract

`reboot` flushes every currently valid registered disk before invoking
`platform-reboot`. Flush failures are logged and reboot proceeds because this
path has no synchronous recovery mechanism. If a snapshot is in progress, the
reboot waits for `wait-for-snapshot-completion` before tearing down platform
state.

## Verification

`Lambda64/tests/host/test-supervisor-reboot-sync-contract.sh` checks disk flush
ordering, snapshot wait gating, and platform reboot sequencing.
