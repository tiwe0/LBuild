# TF-WI-0419: Unsigned range bounds check

- **Status:** completed
- **Owner:** runtime
- **Scope:** `Lambda64/runtime/runtime.lisp`

## Change

`%bounds-check-range` now guards the size-minus-range subtraction, then uses
`%fixnum-<-unsigned` to combine the non-negative index and upper-bound checks.
The guard prevents unsigned underflow when the requested range exceeds the
object size.
