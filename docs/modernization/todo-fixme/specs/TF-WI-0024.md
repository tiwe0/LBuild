# TF-WI-0024: Use compact block numbering in dominance analysis

## Scope

Dominance currently keys intermediate structures by basic-block objects. Replacing these hash tables with numbered arrays is an optimization with algorithmic and memory impact; retain until benchmark and equivalence evidence exists.

## Required evidence

Add focused host, compiler/codegen, and (where applicable) cold-image tests
covering success, boundary, and failure behavior before removing the marker.
