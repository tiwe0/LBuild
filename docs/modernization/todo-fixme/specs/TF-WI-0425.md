# TF-WI-0425: GC finalizer reporting isolation

## Change

Finalizer error reporting is wrapped in `ignore-errors`. The supervisor console
is diagnostic infrastructure and must not allow its own failure to abort the
remaining finalizer queue; `unwind-protect` still clears each weak pointer.
