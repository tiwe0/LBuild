# TF-WI-0200 — `copy-string-in-area` 的 displaced string 支持

- **基线标记：** `TF-occ-92f5176ff5eeaf04e0b31783`
- **代码事实源：** `Lambda64/runtime/string.lisp:115-184`
- **风险：** critical
- **要求测试层：** host、cold-image、integration

## 目标

`copy-string-in-area` 现在可复制非直接 character array 的 string，即 displaced
character vector。它在指定 allocation area 创建独立 simple string，长度使用源
fill-pointer（若存在），并通过既有 `char` 访问器复制每个字符，因而保留 Unicode
码点及 destination backing storage 的自动扩宽逻辑。源 array 和其 displacement 不会
被修改。

## 先测试证据

`Lambda64/tests/host/test-runtime-string-displaced-copy.sh` 在旧实现上失败，错误为：

```text
TODO: copy non-character-array strings
```

该回归以表示层 fixture 覆盖 displaced source、`:wired` allocation area、fill-pointer
有效长度、Latin/Greek/CJK 字符复制与源对象不变，并带有将 source character 替换为
常量的 mutation 负例。
