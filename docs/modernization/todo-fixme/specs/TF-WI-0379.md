# TF-WI-0379: Circular cons LLF serialization

## Scope

This work item makes LLF cons serialization safe for cycles through any
serializable container, including a proper CDR spine whose CAR points back
into the graph and a cons/vector mixed cycle.

## Required behavior

The LLF v37 writer emits `+LLF-ALLOCATE-CONS+`, installs and retains the object
backlink, serializes CAR and CDR, then emits `+LLF-INITIALIZE-CONS+`. Both the
runtime loader and cold generator implement the paired commands. Consequently
recursive encounters resolve through a completed backlink instead of
re-entering a `:save-in-progress` object, and no compiler-generated
initialization function needs to serialize ordinary compiler AST conses.

## Acceptance evidence

`Lambda64/tests/host/test-system-file-compiler-semantics.sh` verifies the v37
header and command definitions, checks both loaders contain the paired
handlers, and exercises production two-pass serialization of a
`cons → simple-vector → same cons` graph. It asserts allocation precedes both
edges, the backlink is emitted, and native initialization is present. It also
rejects missing allocation and missing backlink mutations. `make test-codegen`
compiles the real ARM64 regression without the former control-stack recursion.

A complete serialize/load identity check requires the Mezzano LLF loader in a
cold image and remains outstanding, so status is `active`.
