# TF-WI-0374: DMA fault ownership metadata boundary

`raise-memory-fault` identifies expired DMA addresses by range, but does not
map an address back to its owning buffer. The current condition reports the
address only. Tracking ownership requires lifecycle-safe metadata shared with
the DMA allocator and fault path, so the marker remains an explicit boundary
until host, cold-image, and integration coverage exists.
