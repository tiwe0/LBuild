# TF-WI-0375: Nested macrolet definition environment

## Scope

This work item closes the macrolet-environment marker formerly present in
`Lambda64/system/file-compiler.lisp`. It preserves the Common Lisp rule that a
local macro definition is interpreted in the surrounding macro-definition
environment, without making sibling definitions recursively visible.

## Required behavior

`make-macrolet-env` evaluates each generated expansion function through
`eval-in-lexenv` and the outer environment filtered by
`environment-macro-definitions-only`. Outer macrolets and symbol macros are
therefore visible in macro definition bodies; unrelated lexical bindings are
not captured, and the new definitions are installed only after creation.

## Acceptance evidence

`Lambda64/tests/host/test-system-file-compiler-semantics.sh` extracts and calls
the production function and verifies the filtered outer environment reaches
expansion-function evaluation. With the pre-change `HEAD` source the focused
command exits 1 at the source-contract gate; with the implementation it prints
`system file compiler semantics passed`.

The required cold-image and integration runs have not yet been recorded, so
this specification remains `active`.
