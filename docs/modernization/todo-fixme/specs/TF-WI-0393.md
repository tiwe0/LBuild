# TF-WI-0393: Define obsolete-instance forwarding concurrency boundary

## Scope

Close the race-condition FIXME in `Lambda64/system/gc.lisp` during obsolete
instance transport.

## Contract

When an obsolete instance has `layout-new-instance`, GC forwards references to
the replacement and preserves funcallable entry fields. A mutator that captured
the old slot layout before forwarding may still race with this optimization;
correct callers must execute such accesses in a GC restart region. This change
documents the boundary and does not claim a new restart protocol.

## Verification

`Lambda64/tests/host/test-system-gc-boundaries.sh` checks the explicit
concurrency/restart contract and marker removal. Cold-image and integration
validation remain required before closing this high-risk work item.
