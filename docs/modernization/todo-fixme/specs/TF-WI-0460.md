# TF-WI-0460: Implement architecture-aware DMA buffer cache flushing

## Scope

Close the cache-flush TODO in `Lambda64/supervisor/dma-buffer.lisp`.

## Contract

`dma-buffer-cache-flush` now validates the requested subrange and invokes the
architecture-provided `clean-and-invalidate-cache-range` primitive when one is
available (currently ARM64). Architectures without a cache maintenance API
retain the existing `dma-write-barrier` ordering fallback rather than issuing
unsupported instructions. Uncached buffers remain a no-op.

## Verification

`Lambda64/tests/host/test-supervisor-dma-buffer-cache-flush.sh` checks removal of
the TODO, range validation, architecture hook, and fallback barrier contract.
