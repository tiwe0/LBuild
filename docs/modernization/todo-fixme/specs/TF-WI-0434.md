# TF-WI-0434 — Pprint dispatch table synchronization

## Contract

`pprint-dispatch-table` mutations update synchronized hash tables and the
priority-ordered `others` list as one logical operation. Concurrent readers
must not observe the list or entry priority counters halfway through an
update.

## Implementation

Each dispatch table owns a supervisor mutex. Copying a table, dispatch lookup,
and `set-pprint-dispatch+` hold that mutex for their complete operation;
existing synchronized hash-table locks remain in place for storage safety.

## Verification

`Lambda64/tests/host/test-system-xp-dispatch-lock.sh` checks the lock contract
and runs a mutation-aware negative check that rejects removal of the lock
wrappers. Run with `bash -n` and execute the script from the repository root.
