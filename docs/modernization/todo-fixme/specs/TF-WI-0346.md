# TF-WI-0346: Method-combination resolution dispatch prototype

`resolve-method-combination` now dispatches `find-method-combination` using the
prototype of `standard-generic-function`, the class expected by the generic
function's methods. It no longer passes the unrelated `class-name` generic
function merely as a dispatch object. This is required while `DEFGENERIC` is
still constructing the eventual generic function.

`Lambda64/tests/host/test-system-method-combination-resolution.sh` checks the
source contract and rejects a mutation restoring `#'class-name`. Full CLOS
bootstrap/integration execution is not recorded by this focused host check.
