# TF-WI-0368: ARM64 register-offset address scaling

## Scope

Close the address-decode FIXME in
`Lambda64/system/disassemble-arm64.lisp` for register-offset load/store
instructions. The optional register shift is scaled by transfer width;
SIMD/FP Q forms use a 16-byte transfer and add four to the encoded `size`.

## Acceptance evidence

`Lambda64/tests/host/test-system-disassemble-arm64-offset.sh` verifies the
computed scale and rejects a mutation that substitutes raw `size`.
