# TF-WI-0273: Minimum wired boot reserve contract

## Scope

This item protects the next boot from snapshots with no usable wired allocation
reserve.

## Required behavior

Immediately before copying, while CPUs are stopped and the VM is locked, the
snapshotter computes the largest contiguous wired freelist entry. It refuses to
commit a snapshot unless at least 64 KiB is available in one region. Summing
fragmented entries is insufficient.

## Test-before evidence

The focused test reported the former 64 KiB TODO; no precondition checked the
wired freelist.

## Acceptance evidence

The executable host regression supplies fragmented fake freelist bins and
verifies the largest-region calculation and 64 KiB acceptance. A guest test
must still exhaust wired memory and verify refusal without damaging the prior
bootable snapshot.
