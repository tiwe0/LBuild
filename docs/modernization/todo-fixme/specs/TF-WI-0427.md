# TF-WI-0427: NaN-safe generic relational predicates

## Change

`generic->=` and `generic-<=` now use strict comparison-or-equality instead
of negating the opposite comparison. IEEE NaN values therefore remain
unordered: all relational predicates return false for NaN operands.
