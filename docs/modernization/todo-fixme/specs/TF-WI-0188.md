# TF-WI-0188: ARM64 fixnum shift bignum construction boundary

The ARM64 fast path deliberately branches to `%fixnum-left-shift-slow` when
range checks detect overflow. Constructing a bignum inline would alter the
allocation/GC ABI and must preserve negative shifts, large counts, and
canonicalization.

Required evidence: ARM64 codegen plus guest and host boundary tests, including
all overflow branches, before changing the slow-path handoff.
