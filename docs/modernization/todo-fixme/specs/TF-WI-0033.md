# TF-WI-0033: Emit x86-64 NLX jump tables as trailers

## Scope

`Lambda64/compiler/backend/x86-64/codegen.lisp:851`.

## Current boundary

NLX jump-table words are emitted inline. Moving them to a trailer changes label placement, RIP-relative offsets, alignment, and cold-image serialization; retain this marker until codegen and runtime NLX tests cover all target counts.

## Required evidence

Add focused code-generation and cold-image/runtime tests for zero, one, and many targets, including relocation/alignment validation, before removing the marker.
