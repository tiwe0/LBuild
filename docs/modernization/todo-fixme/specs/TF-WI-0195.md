# TF-WI-0195 — SIMD `AREF` 的非一维与 displaced array 支持

- **基线标记：** `TF-occ-188eeb2459ab84769d217a7c`
- **代码事实源：** `Lambda64/runtime/simd-arm64.lisp:285-340`
- **风险：** critical
- **要求测试层：** host、cold-image、integration

## 目标

SIMD `AREF` wrapper 不应把输入限制为一维 simple array。对于普通多维数组和
displaced array，wrapper 必须解析连续的 simple backing vector，并将 displacement
offset 加入 row-major index；不支持向量化访问的 memory-array backing storage 仍应
明确拒绝，而不是把裸地址当作数组对象传给 builtin。

## 先测试证据

新增 `Lambda64/tests/host/test-runtime-simd-non1d-arrays.sh`，检查生产宏接受
`(array scalar-type *)`、调用 `array-displacement`、校验 simple backing storage，并
把 `offset` 加入最终 index。变异负例恢复 `(simple-array scalar-type *)` 时必须被拒绝。

## 验收标准

1. 普通多维数组的 SIMD row-major 访问使用其一维 backing vector。
2. displaced array 的访问保留 displacement offset，读取和写入使用同一索引转换。
3. 原有一维 simple array 行为保持不变，越界检查仍覆盖全部 lane。
4. memory-array backing storage 在向量化 wrapper 中通过类型检查明确失败，不执行
   不安全的裸地址访问。
5. codegen、cold image 和 integration 验证待完整构建/Quicklisp 环境恢复后执行，
   工作项保持 `active`。

## 当前证据

```sh
bash -n Lambda64/tests/host/test-runtime-simd-non1d-arrays.sh
bash Lambda64/tests/host/test-runtime-simd-non1d-arrays.sh
```

以上 host 合约测试通过，并确认恢复旧的一维类型限制的变异会失败。完整 codegen、
