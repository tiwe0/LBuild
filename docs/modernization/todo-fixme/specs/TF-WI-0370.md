# TF-WI-0370: Decode ARM64 literal-pool loads by instruction width

## Scope

The ARM64 disassembler's PC-relative literal-pool path must use the decoded
instruction and register to select W/X/LDRSW or S/D/Q width and representation.

## Current boundary

The existing print path uses a single 64-bit read from `target - 8`, which is
not sufficient for all literal forms and can read outside a valid pool at the
zero boundary. The current focused tests exercise the decoder but not this
print path, so the marker remains active.

## Required evidence

Add host, cold-image, and integration coverage for each literal width,
including malformed and boundary targets, before removing the marker.
