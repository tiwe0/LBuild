# TF-WI-0420: ARM64 allocation profiling global flag contract

## Change

The ARM64 fast allocation paths document that `*enable-allocation-profiling*`
is a process-global `DEFGLOBAL`. They intentionally load its symbol global cell,
matching the x86-64 fast paths and the definition in `runtime/allocate.lisp`.
No thread-local substitution is made without a runtime ABI contract for one.
