# TF-WI-0420 — `MERGE` circular list 防护

- **基线标记：** `TF-occ-2770f2364483f4c3b51da21c`
- **代码事实源：** `Lambda64/system/sequence.lisp:1223-1255`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`MERGE` 的 list 结果路径在转换输入前检查 circular list。检测到环时应立即发出明确
错误，而不是让 `coerce` 或后续 `merge-lists` 无限遍历；普通 proper list 与 vector
结果路径保持原有行为。

## 先测试证据

新增 `Lambda64/tests/host/test-system-sequence-merge-circular.sh`，检查 list-length
环检测和明确错误消息，并确认删除检测的变异会被拒绝。

## 验收标准

1. 任一输入为 circular list 时，`MERGE` 在有限步骤内失败并报告原因。
2. 空表、proper list 和 vector 输入仍按既有排序/合并逻辑运行。
3. result-type 为 `null` 的长度错误与环检测错误彼此保持可区分。
4. codegen、cold image 和 integration 验证待完整构建环境恢复后执行，工作项保持
   `active`。
