# TF-WI-0287: ARM64 supervisor run queue placement boundary

Supervisor-priority threads on ARM64 remain constrained to the BSP while the
Virtio multi-PE scheduling issue is unresolved. This is a platform scheduling
limitation, not a safe local cleanup; lifting it requires SMP Virtio reprobe
and interrupt-path evidence.

## Verification

The `pop-run-queue` implementation and host scheduler contract tests are the
current evidence. Keep the marker until multi-PE Virtio tests exist.
