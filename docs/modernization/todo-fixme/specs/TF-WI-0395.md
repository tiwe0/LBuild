# TF-WI-0395: Define sparse pinned-card backtracking boundary

## Scope

Close the card-table backtracking TODO in `Lambda64/system/gc.lisp`.

## Contract

`base-address-of-internal-pointer` walks allocations within a card and retreats
one card when no card-table entry is present. Card metadata is sparse, so the
single-card retry is a bounded correctness path; widening the search requires
new complexity/performance evidence and is intentionally deferred.

## Verification

`Lambda64/tests/host/test-system-gc-boundaries.sh` checks the one-card fallback
contract and marker removal. Cold-image and integration validation remain
required before closing this high-risk work item.
