# TF-WI-0422: Character array CAS atomicity boundary

## Change

Character-array CAS now documents its explicit rejection as an atomicity
boundary. Character writes may promote narrow backing storage, so performing CAS
would require a promotion lock or transactional storage protocol. Until that
ABI exists, rejecting CAS avoids reporting a compare-and-swap that can race a
backing-array replacement.
