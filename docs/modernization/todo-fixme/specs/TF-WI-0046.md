# TF-WI-0046 — 跨编译引导流参数的开放状态校验

- **基线标记：** `TF-occ-58219c880307ad3ac1576b72`
- **代码事实源：** `Lambda64/compiler/cross-boot.lisp:418`
- **风险：** critical
- **要求测试层：** host、codegen、cold-image

## 目标

跨编译引导阶段的 `sys.int::frob-stream` 必须在接受显式流前确认其处于打开状态。
它继续将 `nil` 映射为调用方的默认流、`t` 映射为 `*terminal-io*`，并继续对非流值
发出 `type-error`；关闭的流必须发出关联该流的 `stream-error`，不能进入后续引导
I/O 路径。

## 先测试证据

新增 `Lambda64/tests/host/test-compiler-cross-boot-stream-open-state.sh`。测试从生产源
提取实际 `sys.int::frob-stream` 定义，在宿主 Lisp 上用真实 string stream 覆盖打开、
关闭、默认与非流分支。

实现前运行：

```sh
bash Lambda64/tests/host/test-compiler-cross-boot-stream-open-state.sh
```

失败并报告 `closed stream was accepted`，证明原代码只进行了 `stream` 类型检查。

## 验收标准

1. `nil`、`t` 与打开流的原有归一化结果保持不变。
2. 已关闭流在进入引导 I/O 前发出 `stream-error`，且条件的 `:stream` 为原对象。
3. 非流参数仍发出 `type-error`。
4. host 测试直接加载生产定义，并以将 `open-stream-p` 替换为真值的变异负例锁定
   关闭流拒绝路径；codegen 与 cold image 在后续完整测试阶段补齐。
