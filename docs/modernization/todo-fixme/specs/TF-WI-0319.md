# TF-WI-0319 — 结构体 `fixnum` slot 的原子 RMW 直通路径

- **基线标记：** `TF-occ-fb4e31240637eb0d7bbc3d22`
- **代码事实源：** `Lambda64/system/cas.lisp:176-186`
- **运行时事实源：** `Lambda64/runtime/struct.lisp:68-108`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

对结构体访问器执行 `atomic-incf`、`atomic-logandf`、`atomic-logiorf`、
`atomic-logxorf` 时，已声明为 `fixnum` 且可写的 slot 必须使用对应的
`%atomic-fixnum-*-struct-slot` 原子原语，而不是通用 CAS loop。未知 place 仍保留
CAS loop 回退。运行时原语解析 slot location、检查结构体/slot 类型和只读约束，并对
instance backing slot 执行原子对象操作。

仅检查脚本自身成功而未锁定 direct-dispatch 语义。

## 实施

`define-atomic-rmw-operation` 的结构体访问器分支已经把 accessor 的 object、structure
name 和 slot name 传给 operation-specific `struct-slot-function`；仅无法识别为直接
place 的形式进入 CAS loop。移除已完成能力对应的 TODO，并将回退注释改为明确其适用
范围，不改变既有展开或运行时行为。

## 验收标准

1. 结构体 accessor 的 RMW 展开保留 direct `struct-slot-function` 调用。
2. 未知 place 仍生成 CAS loop；既有 symbol 与 cons direct paths 不回归。
3. focused host 测试及其 mutation-negative 契约通过。
4. cold-image 与 QEMU integration 仍待完整目标环境执行；工作项保持 `active`。
