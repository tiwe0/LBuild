# TF-WI-0086: Bound Intel HDA controller reset polling

- **Status:** completed
- **Owner:** Lambda64 io-platform
- **Scope:** `Lambda64/drivers/intel-hda.lisp`

## Change
Controller reset acknowledgement polling now uses a bounded 10,000-iteration
loop with a 1 microsecond pause between reads. A descriptive error is raised
when either reset phase fails to complete, preventing a wedged PCI device from
hanging system probing indefinitely. Stale DMA64 and interrupt TODO markers were
replaced with comments documenting the existing 64-bit address handling and the
intentional RIRB polling design.
