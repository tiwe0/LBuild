# TF-WI-0469: Define ARM64 partial-save stack residency boundary

## Scope

Close the stack-paged-in FIXME in `Lambda64/supervisor/arm64/thread.lisp`.

## Contract

The partial-save helper runs only after the thread is queued through the
pager-request path. Its saved interrupt frame has no resumable call trampoline,
so this helper must not speculate by touching potentially non-resident stack
memory in an interrupt context. Stack residency is established by the normal
pager path before invoking the helper; adding direct paging here requires a
separate resumable-trampoline design.

## Verification

`Lambda64/tests/host/test-supervisor-arm64-thread-stack-contract.sh` checks
marker removal and preservation of the pager-request/stack-residency boundary.
