# TF-WI-0300: Define virtio driver redefinition lifecycle boundary

## Scope

Close the duplicate-driver detach/reprobe TODO in
`Lambda64/supervisor/virtio.lisp`.

## Contract

`virtio-driver` records expose probe metadata but no detach or transport-reset
callback. An incompatible redefinition remains rejected; registration does not
clear device claims or probe live transports. Future reprobe must be preceded
by explicit teardown and transport reset, complementing TF-WI-0461's runtime
detach boundary.

## Verification

`Lambda64/tests/host/test-supervisor-virtio-registration-boundary.sh` checks
marker removal and preservation of the non-destructive registration guard.
