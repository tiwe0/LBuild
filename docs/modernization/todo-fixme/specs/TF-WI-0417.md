# TF-WI-0417: Conservative runtime CONSTANTP constant-folder coverage

## Scope

`Lambda64/system/runtime-support.lisp` now recognizes a deliberately bounded
set of compiler constant-folder operations when every argument is itself a
constant. The whitelist covers arithmetic, integer/logical operations,
comparisons, character/byte operations, numeric predicates, and type
predicates already registered as pure folders by the compiler. It never
executes a function or compiler macro. Lexical function bindings in an
`environment` prevent treating a call as a global pure operation; symbol
macros are expanded only for symbol forms so environment semantics are
preserved without changing ordinary macro expansion.

## Required behavior

* Self-evaluating objects, quoted forms, declared constants, `NIL`, `T`, and
  keywords remain constant.
* Whitelisted calls are constant only when arity and all argument forms prove
  constant recursively.
* Unknown calls, nonconstant arguments, and locally shadowed functions return
  false.
* `CONSTANTP` must not macroexpand arbitrary list forms or invoke arbitrary
  functions.

## Acceptance evidence

`Lambda64/tests/host/test-system-runtime-support-constantp.sh` extracts the
implementation into a host SBCL harness, checks positive and negative cases,
and runs a mutation-aware guard that removes recursive argument checking; the
mutated implementation must fail. Cold-image and full integration execution
are not recorded here.
