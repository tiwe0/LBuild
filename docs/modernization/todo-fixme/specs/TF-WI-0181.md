# TF-WI-0181: SIMD exception operation decoding boundary

`%raise-simd-exception` currently receives an opaque argument and decodes the
pending MXCSR flags, but does not identify the originating operation/operands.
Removing the marker requires an ABI contract for the signal payload and tests
for every unmasked exception class; guessing from MXCSR alone is insufficient.

Required evidence: host tests for payload decoding and exception precedence,
plus x86 trap-path or cold-image coverage before changing this boundary.
