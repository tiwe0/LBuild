# TF-WI-0314 — LOOP typed initializer sized-vector compatibility

- **基线标记：** `TF-occ-b3075226c2c526033def9bf5`
- **代码事实源：** `Lambda64/system/ansi-loop.lisp:1104-1117`
- **风险：** high
- **要求测试层：** host、cold-image、integration

## 目标

`loop-typed-init` 必须为带固定长度的 vector 类型产生满足长度约束的初始值。
类型展开后，单一整数维度通过 `make-array` 直接分配；不定长或多维类型继续
使用空 vector 回退，保持既有 LOOP 初始化行为。

## 验收证据

`Lambda64/tests/host/test-system-ansi-loop-typed-init-vectors.sh` 覆盖 sized-vector
分支、元素类型/维度解析以及 `coerce` 回退，并通过变异测试确认删除直接分配会失败。

```sh
bash -n Lambda64/tests/host/test-system-ansi-loop-typed-init-vectors.sh
bash Lambda64/tests/host/test-system-ansi-loop-typed-init-vectors.sh
```
