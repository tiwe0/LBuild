# TF-WI-0281 — Deferred store overlap checks

## Scope

`store-deferred-free` must not enqueue a range that intersects an already-free
main-freelist range or another deferred range. Deferred entries overlap an
allocated main-freelist range by design; that state is released after snapshot
commit.

## Implementation

The function validates positive lengths, rejects intersections with free main
ranges and existing deferred ranges, and keeps the deferred list ordered while
coalescing adjacent entries.

## Acceptance evidence

`Lambda64/tests/host/test-supervisor-store-deferred-freelist.sh` checks the
production form and mutation-sensitive overlap guards. Cold-image and
integration evidence require the guest VM lock and store runtime.
