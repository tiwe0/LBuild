# TF-WI-0040: Lower x86-64 object type range predicates without fixed RAX

## Scope

`Lambda64/compiler/backend/x86-64/object.lisp:49`.

## Current boundary

The 8-bit type-range predicate is tied to RAX/AL because `x86-instruction` cannot yet map an allocated integer vreg to its 8-bit preg. Keep the marker until that operand model is extended without changing liveness or condition-code semantics.

## Required evidence

Add codegen, cold-image, and host tests covering all allocatable byte-register classes and spill paths before removing the marker.
